## 一、先纠正一处我上一轮的错误结论

上一轮我说「异形不能刀异形是 2.5D 规则」——**错的**。

`js/game.js:4226` 的 `knife()` 只有三道门：
```js
if(!killer||killer.knife<1)return;       // 有刀
if(!victim||!victim.alive||victim.downed)return;  // 目标活着且未倒地
```
**没有任何阵营判断**。`fireShot()`（`js/game.js` 同段）也一样。也就是说 2.5D 允许同阵营互刀/互射，只记危险行为（`G.pendingCrime`）。

3D 在 `sim_state.gd:814` 自己加了 `if not bool(v.get("alien", false))` —— 这是**移植时凭空加的规则**，必须删。这也是「我作为异形刀不了异形」的真正原因。

## 三、P0 硬偏差（已定位到行）

### 3.1 出刀凭空加了阵营过滤（你反馈的「刀不了异形」）

| 项 | 内容 |
|---|---|
| 3D 位置 | `scripts/sim/sim_state.gd:813-814`：`if not bool(v.get("alive", false)) or bool(v.get("alien", false)): return false` |
| 2.5D 真源 | `js/game.js:4226-4230`：只判 `killer.knife>=1` / `victim.alive` / `!victim.downed` |
| 影响 | 异形玩家与 AI 都被禁刀同阵营；**玩家与 AI 用的是同一条错规则**（不是不公平，是规则本身多了一条） |
| 修法 | 删掉 `or bool(v.alien)`；同阵营命中照 2.5D 走"危险行为记账 + 红身 + 目击"，不额外拦截 |
| 验收 | 新增 `--knifetest` 用例：异形 A 刀异形 B → B 必须进入濒死，A 扣刀、`redT` 生效 |

### 3.2 天亮回舱：只改了 sim，玩家没被传送（你反馈的「没回中央会议室」）

| 项 | 内容 |
|---|---|
| 3D 位置 | `sim_state.gd:1502 dawn()`：把每个存活 agent 的 `pos` 设到 bridge 随机点 |
| 漏的一环 | 玩家相机/角色节点没跟着改。`main._sync_player_pos()` 在会议结束后会用**相机位置反向覆盖** `me.pos` |
| 结果 | AI 会走/瞬移到会议室，玩家留在原地；会议结束一帧后 sim 里玩家位置又被拉回原处 |
| 修法 | `dawn()` 触发时，若 `sim.meeting.kind == day`，把 `player.global_position` 设到 bridge 落点并重置 `rotation.y`；同时给 `_sync_player_pos` 加"会议刚结束的 0.5 s 内不反向写"的抑制窗口 |
| 验收 | `--uitest` 加断言：`dawn()` 后 `player.global_position` 与 `sim.me().pos` 距离 < 0.5 m；会议结束后 1 s 仍在 bridge |

### 3.3 暗房没有"暗"的表现（你反馈的引擎/配电室）

| 项 | 内容 |
|---|---|
| 2.5D 真源 | `js/game.js:677 refreshLight()` 三态：`0` 常态（只有 `light==='bright'` 的房间亮）、`1` 电路修好（全亮）、`2` 拉闸（只剩 bridge） |
| 3D 现状 | `map_builder.set_light_state()` 三态逻辑是**对的**（`st==0` 时按 `rec.bright` 关房间灯），但同一函数里 `_fill`（0.28）、`_ceil_fill`（0.16）、环境光 `LIT_AMBIENT` **全部保持全亮** |
| 结果 | 引擎/配电的房间点光确实关了，但被全船补光照亮 → 看起来"没变暗" |
| 2.5D 还差一层 | 2.5D 是**画布遮黑**：未点亮的房间整块压暗，人类只能靠手电（7 m / 60°） |
| 修法 | ① 把 `_fill` 常态降到 0.06、`_ceil_fill` 降到 0.04；② 新增"暗房遮罩"：玩家所在房间 `light!=='bright'` 且非 DEV/旁观时，全屏黑幕 alpha≈0.55（0.2 s 淡入），手电保留；③ 门缝/指示灯保留低自发光做引导 |
| 验收 | 截图对照：常态进 engine / power 必须"只能看见手电圈"；修好电路后全亮；拉闸后连走廊全黑 |

### 3.4 左上角信息面泄露（你反馈的「谁被驱逐/谁做完任务」）

| 项 | 内容 |
|---|---|
| 3D 位置 | `main.gd:7056 _event_feed()`：把最近 4 条事件写成 `X 完成 任务` / `X 被驱逐` / `X 领取补给` |
| 2.5D 真源 | 局内 HUD 只显示：夜/计时、维修进度、自己的任务、存活数、报告额度；**任务完成与驱逐不实时播报**（只在复盘页 `js/ui/replay.js`） |
| 影响 | 直接泄露"某人刚做完任务/某人被驱逐"，破坏推理 |
| 修法 | 删掉 `task` / `eject` / `supply` 三类；只保留**公共可感知**的：`发现尸体·开会`、`设备故障·舱室`、`故障修复`、`停电/恢复`。文案与 2.5D HUD 对齐 |

### 3.5 顺带确认的两条（不是 bug，但要知道）

- **夜间会议不传送**：2.5D `openMeeting('night')` 只清路径、不挪人（`js/game.js:6936`）；只有 `dawn()` 的白天会议才全员回 bridge。3D 的 `dawn()` 逻辑方向正确，坏在 §3.2。
- **会议期间玩家被锁**：`main.gd:5484` 设 `player.ui_locked=true`，与 2.5D 一致。
