### 关于「继承」

这个项目是**从废案重构出来的**：它继承自同一仓库的太空杀旧设计，吸收了两个副分支
（`form-ui-original` / `过渡版`）留下的**遗产设计**——表单式的证据链与发言结构、
`js/ai/voice.js` 的「话题式发言层」、`SKTrait` 的性格轴与效用函数思路，
以及那套「先声明、再实现、用审计断言防漂移」的工程纪律。

但**遗产只借结构、不借行为**：旧分支是为表单式对局服务的，直接搬到实时对局会毁掉节奏，
所以这里只保留它验证过的抽象（证据分类、发言话题、性格档位、审计式门禁），
具体阈值与判定全部按实时对抗重写。旧分支本体保存在标签 `space-kill-final`
与两个副分支上，随时可对照。

## 快速开始

| 方式 | 做法 |
|---|---|
| 直接运行 | 双击 `index.html`（推荐 Chrome / Edge；手机请横屏） |
| 本地服务 | `npm start` → <http://127.0.0.1:5173> |
| 回归门禁 | `npm test`（依赖本仓 `playwright-core@^1.64.1`，见[开发与测试](#开发与测试)） |
| 蒙特卡洛 | `npm run sim`（1000 局 AI 对 AI；汇总 `tools/mc-report.md` 入库，原始局入库形态为 `tools/mc-results.json.gz`） |
| 语料体检 | `node tools/lines-audit.cjs`（零依赖，不开浏览器；`--strict` 有 FAIL 就退出码 1） |

开始页选择「人类」「异形」进入对局，或选「旁观者」作为**第 16 人**观战；每局仍是 15 席（11 人类 + 4 异形），全部由 AI 托管，旁观者不参与任何判定。

## 玩法概要

- **人类**：完成自己的 4 个维修任务（1 高难 + 3 普通），并和队友把全船维修进度推到 45 分；或清剿全部异形。
- **异形**：出刀（含对队友）、开枪、钻管道、拉闸、停摆机器人，并可用**每夜一次的破坏技**选一处非会议室舱室下手，削减人类数量。
  异形之间**互不知道身份**；AI 不读取任何队友信息，目标、会议指控和投票都不按阵营过滤，
  因此异形也可能攻击或投掉同类。人类只有目击异形专属行为（出刀 / 钻管道 / 破坏设备 / 停摆机器人）
  才会把对方列为嫌疑人。
- **物资申请单**：每人 4 个任务（1 高难 +2 分 / 3 普通 +1 分）。积分到 3 / 5 只生成「待领取申请单」；
  必须回中央会议室**圆桌**按 `E` 站桩 3 秒领取一张申请单；再到军械库 / 医疗间的**专用补给点**
  按 `E` 消耗 1 张申请单换子弹或医疗包。未领取时补给点会明确拒绝。
- **会议**：发现尸体按 `R` 报告，或点击尸体搜尸后报告；自由发言阶段 AI 会盘口供、质疑与作证，随后投票驱逐并**公布身份**。
  讨论和投票都可以「跳过」：跳过讨论直接进入投票；投票有 **15 秒**，点「跳过投票」会结束剩余时间
  （已经投给谁就保留那一票，没投才算弃权）。
- **设施**：配电室电闸（**拉闸与合闸解耦，任何活人都能做**：拉闸按**本夜第几次**递增
  **3 / 6 / 9 / 9… 秒**，只有真正把灯拉黑才计数；合闸**恒 4.5 秒**，做完电路维修后降到 **3 秒**。
  AI 异形会评估本次拉闸的暴露窗口：6 秒起有人看得见就放弃，9 秒时只有确认无人时才动手）、
  监控室 10 路画面（10 间舱室全覆盖，含仓库；显示真实角色，不是小点）、
  医疗无人机（**每夜 2 次电量**：悬停在医疗间正中央，有人濒死就飞过去做 **3 秒近身治疗**再拉起，
  不再隔空读条，也不对外播报「谁被救起」）、
  保安机器人（**10.5 格 / 180° 半圆**内**先近身追捕、压制、再押送到军械库角落**，拘留 **30 秒**，每夜最多 2 次）、
  中央会议室圆桌申请单、军械 / 医疗专用补给点，以及 22 扇**自动门**（无人闭合、靠近滑开，关门时阻挡移动与视线）。
  医疗无人机**不巡逻**（坞位就是房间正中央），覆盖整间医疗间；保安机器人仍走 4 点巡逻，拘留与交互按实时位置判定；
  保安 / 医疗无人机都有装甲，可被出刀或开枪摧毁（保安 HP 2 / 无人机 HP 1），保安机器人会反制拘留攻击者。
  监控台与电闸的**本体**由 Blender 建模、面板/屏幕用 SDXL 材质
  （`assets/scene/v4/tex/facility-panel.png` / `facility-screen.png`）烘进底图；
  监控台的屏幕**斜躺在主控台**上（6 段递减薄板拼约 20° 俯仰），锚点在主控台 `(79.35, 36.0)`；
  医疗无人机与保安机器人仍是运行时精灵（`tools/gen-facility-sprites.py` 出图，统一降饱和冷调）。
  **每个舱室墙角都装了监控摄像头**（纯装饰布景，不参与视野与判定）。
  **机器人被摧毁、有人被拘押都不再有全局播报**，只能靠火花 / 警报特效与在场目击者自己判断。
  拘留是**公开可见**的行为：10 格内**看得见**押送的人会记一条 `saw_detain`（嫌疑 +0.6，并把这个
  被押走的人列为首要怀疑），但**绝不写确证**——被保安抓的可能是开枪的人类；
  远处的人只听得见警报（`heard_detain`），记忆里有这笔记录却认不出是谁，也不加任何人的嫌疑。
- **硬掩体**：房间内的家具 / 培养罐 / 货箱是真实阻挡，不能穿过；掩体布局保证每个房间有连通绕行通道，
  不存在夹缝走不过去或掩体制造的尽端死路（门禁 `coverAudit()` 零夹缝 / 零死路）。
  家具表面材质由 `tools/gen-materials.py` 用本地 SDXL 生成（金属板 / 钢板货箱 / 织物 / 复合台面 / 医疗白板），
  统一降饱和冷调到地板与墙面同一色温；Blender 侧补齐倒角、包边、螺栓、散热百叶、地面警戒框与接地软阴影，
  避免“方块贴纸感”。
- **门是顶面视角**：自动门只画「门的最上面一层」——横门 / 竖门只是旋转 90°，从上下左右看都一样，
  不再露出一整块门板正立面（Blender 端也去掉了门楣与高处灯带）。
- **断电门禁**：断电期间，**全船每一扇门（含会议室三门）在有人靠近时都要先扫描 2 秒**才放行（红色扫描线），
  人离开后重新上锁；恢复供电立即解除扫描。直到电力恢复为止，每次过门都要重新等这 2 秒。
- **亮房整间可见**：站在亮着的舱室里，**整间房的人都直接可见**（家具 / 掩体不再挡住“看人”，
  与迷雾整屋揭开一致）；暗房或熄灯房间才退回 7 格手电锥 + 近身视野。
  **这条对 AI 同样成立**（2026-11-03 用户裁定）：`aiCanSee` 与玩家 `visibleAt` 共用同一条亮区规则，
  站在亮会议室另一头的人，AI 看得见——以前 AI 被 8 格上限截断，比它自己扮演的角色还弱。
- **走廊默认有灯**：未断电时走廊和亮房一样默认开灯——站在亮走廊里能看清**整条走廊**上的人，
  不再依赖手电朝向；从亮舱看进相连走廊按视线结算。断电后走廊灯全熄，才退回手电锥 + 近身视野。
  AI 也一样：同一条亮走廊整条可见，不再受 8 格上限约束。
- **事件流与复盘**：整局记录 `G.events`——谁在哪出刀 / 开枪 / 死亡（含凶器与凶手）、谁完成哪个任务或修好故障、
  谁钻管道（起点→终点）、谁拉闸 / 合闸、谁拖起 / 放下谁、谁搜了谁、谁领取 / 兑换物资、谁被拘留，
  以及每场会议、每句发言、每张票、驱逐结果与“尸体被拖离医疗间”的反常行为。结束后可**保存回放**（JSON：事件流 + 每 0.5 秒的 15 人位置帧 + 身份表），
  也可以直接在游戏内打开**复盘页**：拖时间轴看 15 个席位在船上移动、点事件高亮对应舱室；
  待领申请单会常驻 HUD 提示并在小地图给圆桌金色脉冲；
  开始页还提供「载入回放」，之前保存的文件可以随时重开复盘。
- **异形视野**：异形拿**和人类同款的手电筒**（7 格 / 60° 锥形），不再有全向远视野；
  只有自带近身感知半径大一些（人类暗处 **2.8 格** → 异形暗处 **3.5 格**，`SKSanity.SIGHT` 直接给数值），
  黑暗里更容易察觉贴到身边的人。亮舱 / 亮走廊里异形与人类玩家看得见完全同一批人。
- **旁观者**：第 16 人不占席位、不可交互/搜尸/收尸/投票，但拥有全知视角与 9 格/秒的穿墙幽灵相机，
  HUD 会切成旁观者面板并常显全知总览；会议中额外保留**「跳过讨论（旁观）」**按钮，只快进讨论，不发言也不投票。
  **0 号星尘由 AI 完整托管**（独立发言、投票、行动），DEV 名单标「AI」而不是「你」。
- **设置**：开始页与暂停面板都能打开设置——音乐 / 音效音量（写 localStorage）、暂停 / 继续、退出到开始页。
- **任务提示**：自己的任务点不再套黄色虚线框，而是**让所在家具本体发出金色脉冲**
  （从烘焙底图裁出该掩体的像素做 `screen` 叠加），目标读起来是“那台机器在闪”，不是“框里有东西”。
- **破坏与抢修**：每个异形每夜一次破坏技，按 `H` 选择除中央会议室外的任意舱室，抵达后损毁该舱室设备；
  故障有 30 秒窗口，人类或异形站在设备旁按 `E` **连续维修 10 秒**即可排除（移动会打断）。
  30 秒内未修完且天还没亮，维修进度 **-5**；天亮时未修完的故障不追罚。幽灵不能破坏；
  **人类幽灵**（玩家与 AI）可以修任务/故障（1.6×，最多 2 分任务进度），**异形幽灵不执行任何维修/任务**。
- **站桩维修**：任务维修与故障维修都必须站在设备旁；移动会立即打断并重置计时，不再是“边跑边修”。
- **地图**：**10 间舱室**（新增 504 格**仓库**：位于中央会议室正上方、10 格中等长度通道连接、单门、可被监控室看到；
  中转间改为**食堂**并换掉全部内置物品与地板贴图；食堂↔娱乐室的通道已封闭）· **26 个维修点**（8 高难 + 18 普通）·
  **6 个管道口**（引擎 / 监控 / 军械 / 仓库 / 食堂 / 医疗间）· 22 扇自动门 · **59 件硬掩体**（桌椅/柜子/机器全部真实阻挡）；
  整船边界 **98×94**——仓库与加长走廊（食堂↔医疗、桥楼↔食堂、中转↔医疗、军械↔医疗）都是扩出来的，不是硬塞进会议室。管道只有异形可用，人类无法打开。
- **移速**：所有活人统一 **4.2 格/秒**（2026-10-31 从 4 上调）；拖尸 **2.7 格/秒**，玩家幽灵 6.5 格/秒是显式例外。
  2026-11-03 加一档**击杀加速**：异形放倒人后 3 秒内 **×1.5（=6.3 格/秒）**，拖尸期间不加速（次序：拖尸 > 加速 > 基础）。
- **任务时长**：高难统一 **12 秒**（配电室的**电路维修 15 秒**），普通统一 **8 秒**（2026-10-31 从 15/18/10 下调）；
  专用补给点兑换：**子弹 7 秒、医疗包 5 秒**（原 10 / 6 秒）。
- **濒死与拖尸**：被击倒后进入濒死，可被医疗无人机（**每夜 2 次电量、飞过去近身治疗 3 秒**）或医疗包救起；尸体可拖拽藏匿，搜尸可得到死因与移动痕迹。
  **AI 同样会用拖拽**：没有医疗包的人类 AI 会把濒死者一路拖进医疗间交给机器人；异形 AI 会把尸体拖到
  远离门与任务点的舱室角落藏起来（医疗间 / 会议室的尸体会被拖去别的舱室）。
- **搜尸会取走物资**：尸体会保留生前没花掉的**子弹 / 医疗包 / 物资申请单**；搜一次既取证（伤口、时间、是否被拖动）
  也把能带走的物资收进背包，背包装不下就留在尸体上，下一个人还能来搜。**AI 人类与 AI 异形都会搜尸取物资**。
- **收尸**：`D` 扛起尸体（移动降到 2.5 格/秒，尸体跟在身后），再按一次放下；报告、搜尸、收尸、施救
  都可以从 `W`/`E` 的交互轮盘里选，不用记一堆散键。
- **出刀者会发红**：任何角色出刀命中后，自身会有 **3 秒红身**（角色贴图染红 + 红色轮廓光），
  目击者更容易认出刚动手的人；红身只是表现层，不改变任何判定。

## AI 与规则模型

本作没有接入外部大模型，所有 AI 都是 `js/game.js` 内的本地规则模型：

- **性格轴（`js/ai/traits.js`）**：每个局内 AI 固定一套四轴档位——
  **激进 aggr / 谨慎 caut / 社交 soc / 好奇 cur**（三档分布 28/50/72，每局保证有敢冲的、怂的、和事佬）。
  性格**真实改变行为**：激进的人更敢在目击者面前出刀、开枪门槛更低、投票几乎不弃权、开局就冲；
  谨慎的相反。所有系数集中在 `SKTrait.C`（声明层唯一真源），业务代码不写魔法数。
  门禁有一条「激进 vs 谨慎系数差」组断言锁方向。
- **情绪记忆（`mind.trust` / `mind.grudge`）**：AI 会记仇也会记恩。
  被谁当众咬过（指控/反咬）→ `grudge` 上升，激进的人大概率下次把票砸回去；
  被谁当众护过（辩护/「别投他」）→ `trust` 上升，`trust ≥ 0.8` 的恩人**不过票**。
  **玩家发言同样写入**：你在会议里指控谁、保谁，都会真实改变 AI 对你的态度——
  嘴上赢不了的人，票上会输。情绪跨会议保留、每场衰减 20%。
- **证据分级：多远才算「亲眼确证」（2026-11-02）**：贴脸（≤ **4.5 格**）看见出刀 / 钻管道 / 破坏 /
  停摆 / 拉闸 / 红光 → 写 `known`，会议里敢说「我确定」；**隔着几格看见只算「那边有人动手」**——
  照旧加嫌疑（喂 `almost.foe`），但**不写确证**。这一刀把「抓现行」的确定性拉下来，
  判决权交回给推演：实测每局确证写入 **8.55 → 6.2 次**。
- **准-确证升级为票权 + 「基本是好人」挡票**：手上有一条活着的 `almost.foe` 就优先投他
  （与「已经公开指控过」同级，仍然不是锁死，可被洗清/降级）；`almost.friend` 则以 45% 概率直接弃票 ——
  **这是异形伪装唯一的兑现口**。实测 `almost` 相关的票从 1.84 张涨到 4.5 张、由它驱动的驱逐 1.28 次/局。
- **软联盟（连坐）**：**反复**替同一个人说话（≥2 次）才算联盟；那人翻出是异形时，
  保人吃一笔 `ally_revealed`（0.16×1.7），并说一句「我上次看走眼了」。只做一档，
  不做传递闭包、也不做「共同指控」的连坐 —— 那会把会议变成连坐机器。
- **被带节奏（2026-11-02）**：已经有两三个人公开咬同一个人时，观望者跟票的嫌疑门槛从 0.18 降到 0.10。
  真人局最常见的一类误判不是证据变强，而是**气势起来了**；异形伪证正是在这里兑现。
- **在场反驳（2026-11-01）**：有人说「我在配电室看见他出刀」，而另一个 AI **当时也在配电室**（亮房整间可见）
  却没看见他 → 反过来怀疑**指认者**（`presence_deny`，权重 0.16，弱于正面矛盾的 0.28）。
  只在**亮房**成立，暗房/走廊不适用 —— 「没看见」不能当万能反驳。
- **白天结论回流到夜间走位（2026-11-01）**：会上被谁咬得最狠（他对我的嫌疑最高），
  夜里空闲时我会**主动往远离他的方向走** —— 不是数值加成，是行为真的变了，
  而且这条回避本身是**可被看见**的，白天又能被拿去当证据用。
- **AI 认知链**：每个 AI 维护自己的 `mind`（事件记忆 / 嫌疑分 / 证据理由 / 警觉度）。
  只记录自己**看见、听见或搜查到**的事实：刀击、枪声、尖叫、管道、拉闸、故障、机器人停摆、
  自动门、灯光变化、拖尸、保安拘留、尸体伤口/是否被移动/是否已检查，以及时间线里见过的人。
  事实进入证据链后按权重累加嫌疑分，再驱动报告、追凶、开枪、指控与投票；AI 不读取任何 `alien` 身份答案。
- **规则不是阵营禁区**：搜尸取物资、开枪、补给、假装维修、做任务换弹这些规则双方都会按概率使用，
  区别在动机与频率——人类日常做任务/维修，异形通常不做任务，只有为了拿子弹继续杀人时才会做；
  异形会假装维修来制造不在场。AI 仍然有阵营目标差异，不是“同一种行为脚本”。
- **AI 推理链扩展**：会用目击时间线给不在场的人**反向洗清**（`alibi_clear`），会判断枪击是否处决
  （目击者自己确证过被害者是异形时，`saw_shot.justified` 不怀疑开枪者），零证据指控会损耗发言者可信度
  （`empty_accuse`），替已被确证的异形辩护也会引来“同伙”嫌疑（`defended_suspect`）。
- **时间线拆谎的量词（2026-11-01 修）**：`saw_agent` 是**位置时间线**（同一个人每 3.5 秒最多一条，
  一晚上有十几条不同舱室的记录），所以对质绝不能写成「存在一条不匹配 → 定罪」——
  那等于拿 30 秒前的旧位置去否定现在的口供，AI 会一本正经地指控一个说真话的人。
  现在统一走 `checkAlibi()`（数学在 `SKSanity.checkAlibi`，取窗口在 `game.js`）：
  **窗口内只要有一条记录与口供一致，口供就成立、不可定罪**；窗口内一条记录都没有（`checked=0`）
  就闭嘴；只有**所有**记录都对不上才成立 `contradiction`，证据取最接近案发 / 口供时刻的那条。
  时间窗按调用点区分：案发会议用**死亡时刻 ±8 秒**，假口供 / 玩家口供用「口供所指时段」
  （说「刚才」只比最近 20 秒、说「一直/整晚」比整夜、没说时段按 45 秒），**不再按条数 `slice(-24)` 截取**。
  走廊记录不算「在某个舱室」（走过一段走廊不能反驳口供）。
  发言也会带上证据新鲜度：**刚才 / 十几秒前 / 半分钟前**，让听众能自己判断这条证据是不是过期的。
- **外观一致**：异形与人类使用同一套角色贴图、名字标签和状态；空闲时都不显示武器，只有真实出刀 / 开枪
  动作才亮刀 / 枪；DEV / 旁观者的身份标签是唯一的全知例外，不影响正常对局看到的外观。
- **嫌疑的四层演进链（2026-11-01）**：印象 `cred` → 痕迹 `sus`（**跨夜衰减**）→ 准-确证 `almost`（可推翻）
  → 确证 `known`（不可动摇）。
  · **痕迹跨夜**：`sus` 不再一夜清零 —— 目击类每夜 ×0.72、传闻类 ×0.45、本夜无新证据再 ×0.55，
    存量封顶 **0.45**，且**夜间行动读取时再打 0.7 折**（跨夜存量不得单独越过开枪/报警门槛）。
  · **准-确证（双向）**：`sus≥0.70` + **≥2 类非传闻证据** → `almost.foe`（「我基本确定」，投票更狠、开枪门槛 ×0.7）；
    `cred≥0.40` + ≥2 类正经行为 → `almost.friend`（「这人基本是好人」，替他说情、更舍不得投/开枪）。
    两者都**不写 `known`**，且证据一淡就自动降级 —— 这正是它与确证的区别。
  · **硬覆盖**：一旦 `known` 写入，立刻删掉 `almost.friend`、清空 `cred`，此后洗白机制对他一律失效。
    `trust`（他帮过我）不清 —— 那是情绪，和「他是异形」不冲突，清掉反而抹掉「昨天护他、今天咬他」这场戏。
- **证言可信度 `reliability`（2026-11-01）**：和 `cred` 分开 —— `cred` 是「他干的是正经事」，
  `reliability` 是「他的话可信吗」。驱逐翻身份后回写：带对了 +0.35 / 带错了 −0.30（跟票的减半），
  口供被拆穿 −0.20。传闻与指控的权重 ×`(0.5 + reliability)`：**上次带头投错人的人，这次说话没那么值钱**。
- **犹豫与沉默（2026-11-01）**：`sus` 分布的香农熵决定「这一轮要不要点名」——
  熵高（谁都像）就说「我还没看清，先听别人」，**不动弃权率**（弃权率是平衡阀）；
  熵低（一人独高）才敢点名。「他整场一句话没说」也会被记一笔（上限 0.10，**只对白纸生效**：
  本来就有别的疑点的人不再加沉默分），且**永远不会升级成准-确证**。
- **确证（不是嫌疑，是结论，而且会记一辈子）**：亲眼看见**异形专属行为**——
  钻管道 / 出刀 / 破坏设备 / 停摆机器人 / **把电闸拉下去（全船断电那一下）**——
  或看见某人**身上带着刚出刀的 3 秒红光**，AI 会把这个人记进 `mind.known`：嫌疑分直接拉满，
  会议指控点名道姓（「我确定：XX 是异形，我亲眼看见他钻管道」），投票必投他，开枪与追击距离也放宽。
  **`known` 是长期记忆**：位置记忆（`mem`）每夜清空，**嫌疑分改为跨夜衰减**（见上「四层演进链」），
  而确证不随夜晚消失——之后每一场会议都会继续指控并投这个人。
  **开枪、拖尸、拘留、合闸**这些人类也会做的事只增加嫌疑分（或什么都不加），永远不会升级成确证。
- **电闸的两种操作语义相反（2026-11-01）**：同一个人同一台闸，
  **拉闸断电 = 身份级证据**（人类看见→直接写 `known`，异形看见→记成队友 `mates`）；
  **合闸复电 ≠ 证明他是人类**（异形也会合闸伪装），所以人类目击只涨**正向信任 `cred`**
  （「他干的是正经事」），异形目击只涨**人类可疑度 `humanT`**（「这更像对手」，只影响挑目标优先度，
  不写 `mates` / `known`，也不给人洗清嫌疑）。配电室是暗房、闸杆又贴墙，
  **只有紧挨着闸杆的一小条站位看得见**——「守闸」才有确证，隔着半个舱室拉闸没人能指认。
- **AI 人类**：按任务点维修（与玩家同耗时，**做完立刻接下一个，不再休息**）、开局延迟 2–8 秒、
  回中央会议室圆桌领取物资申请单、到军械 / 医疗专用补给点换子弹 / 医疗包、用医疗包救起视线内的濒死者、
  **没有医疗包时把濒死者拖进医疗间交给医疗无人机救回来**（降到 2.7 格/秒、留 `bodyMoved` 痕迹、

  同一夜可以连续开多场会，没有证据时会议投票弃权而不是随机投人。
- **AI 异形**：优先挑**独处目标**（旁边有人看着的对象会加一段风险距离），

  贴脸时只统计**非队友**目击者：
  1 个非队友时 55% 直接冒险出刀；2 个以上非队友时**直接放弃这个目标**，转去找落单者——不再原地来回踱步；

- **机器人**：医疗**无人机**不巡逻（悬停医疗间正中央，覆盖整间，飞过去近身治疗 **3 秒**、每夜 **2 次电量**）；
  保安机器人 **4 点**巡逻，**10.5 格 / 180°** 半圆内**先追捕再押送**、拘留 **30 秒**、每夜最多 2 次。
  两者都可被刀/枪摧毁（保安 HP 2 / 无人机 HP 1），保安会反制攻击者；**摧毁、拘押与无人机救治都不再公告**。
  **异形拆保安有前提**：必须在房间里认出 2 名以上队友、且能推断出一个共同捕杀目标，否则默认不碰
  （落单拆保安=白送一条 `saw_bot` 确证）。
- **报告节奏（2026-10-30 改版）**：不再限制“AI 每晚只开一次会”，改成**每具尸体只报道一次**
  （`reported` 跨夜保留）。**异形会主动报告，但目的不是拖时间了**（2026-11-02）：
  夜晚会议不再占用夜晚时间，"拖"已经没有收益，所以报告的价值改成**误导** ——
  按"场上有没有现成的靶子 / 有没有人适合被栽赃"算收益，按"现场有没有人看着 / 我自己被怀疑多少"算风险
  （表在 `SKSanity.MISLEAD`）。**报告是稀缺资源**：全局每人 2 次、每夜最多 2 场会议。
  **人类只在有实际线索时才报**（警觉度 / 高嫌疑 / 已确定凶手），**一旦确定凶手就一定报告**，
  同样受那 2 次额度限制（用光就只能等别人拉铃）。
- **设计参考**：Among Us 的自我报告 / 假任务 / 会议证据链设计
  （[Guide:Impostor](https://among-us.fandom.com/wiki/Guide:Impostor)、
  [Guide:Report](https://among-us.fandom.com/wiki/Guide:Report)、
  Golechha & Garriga-Alonso, [Among Us: A Sandbox for Measuring and Detecting Agentic Deception](https://arxiv.org/abs/2504.04072)）。
- **已知边界**：普通事件记忆不跨夜；但**确证身份与目击到的队友关系会保留**。没有异形全局队友表/共享目标，
  也没有长文本语义理解；AI 异形**看不到全图位置**（2026-11-03 取消全图锁敌）：
  看得见才用实时坐标，看不见只认本夜亲眼见过的最后位置（`SKSanity.HUNT.memorySec` 25 秒后当作跟丢），
  完全没印象的人根本不进候选；会按目击风险优先挑独处的人，
  也不会主动维修故障（玩家异形可以）；AI 幽灵现在会做任务/故障，但严格受 2 分额度限制。
  玩家自由发言只做关键词/槽位匹配。这些是后续接入模型或扩展规则时的优先项。

## 量化风险表（2026-11-02 节奏批 · 报告变成稀缺资源之后）

> 所有数值只声明在 `js/ai/sanity.js` 的表里（`CARRY / ALMOST / RELIA / MISLEAD / CONFIRM /
> META / AVOID / MEET / FRAME` 与 `js/ai/traits.js` 的 `SKTeam`），业务代码只查表。
> 下表是**给玩家和后续调参用的读法**：每种动作"花掉什么、换回什么、风险在哪、实测多频繁"。

| 动作 | 成本 | 收益 | 风险 / 护栏 | 实测（1000 局） |
|---|---|---|---|---|
| **夜晚报告（人类）** | 全局报告额度 **1/2** + 本夜会议名额 **1/2** | 公开对质 + 投票 + 会上人人自证（自己的嫌疑会被"洗"一部分） | 报告者站在案发现场：旁观者嫌疑 +0.6（`saw_detain`/`heard_*`） | `reportsUsed` **7.12/局**（玩家+AI） |
| **夜晚报告（异形）** | 同上 + 一次"到场暴露" | **误导**：把票压向好栽赃的人；自己摆到"发现者"位置 | `MISLEAD` 表：现场有人看 ×0.30/×0.60、刚被看见 ×0.45、自己被怀疑 −0.30、额度只剩 1 次 ×0.55 | 触发率 < `threshold` 0.30 → 多数时候**不报**（这正是"不是为拖时间而报"） |
| **会议名额** | 每夜 **2 场**（白天会议固定 1 场，不占名额） | 25s 讨论 + 5s 投票，**期间夜晚时钟暂停、任务进度保留** | 用完就不能再开；夜会顶格后报告直接作废 | `meetings` **12.09/局**（夜会约 1.5/场）→ `nightMeetFull` **0**（几乎不撞顶） |
| **出刀** | 刀数 1（不可恢复） | 立即击倒一名人类 | 3 秒红身（= 确证）+ 保安反制 + **开夜前 5 秒禁刀**（`KNIFE.lockAtStart`） | `knives` **11.08** |
| **贴脸目击**（≤4.5 格） | 无 | 写 `known`：不可撤销、必指控、必投票 | 被目击者会反击 / 群殴 | `knownWrites` **7.97** |
| **远距目击**（>4.5 格） | 无 | 只加嫌疑（喂 `almost.foe`） | **不写确证** —— 这是"AI 不再太神"的根 | `farSight` **3.12/局** |
| **构陷**（异形） | 每场会议一次机会（`FRAME.chance` 0.68） | 传闻 +0.26/听众 → 带节奏（≥2 人咬同一人时跟票门槛 0.18→0.10） | 有 `known` 的听众免疫；被拆穿 = 当场反咬（`contradiction_lie`） | `contradictions` **49.3/局** |
| **准-确证 `almost.foe`** | 需 `sus≥0.55` + ≥2 类**非传闻**证据 + 两夜内新鲜 | 投票直接算一票（与公开指控同级）、开枪门槛 ×0.7 | 条件不成立就自动降级；构陷与沉默**不算**证据种类 | `almost` **5.25/局**，驱动驱逐 **0.96/局** |
| **准-确证 `almost.friend`** | 需 `cred≥0.40` + ≥2 类正经行为 | 45% 概率直接挡掉一票（伪装的兑现口） | `known` 一写入立即失效 | 极少（`friendShield` ≈ 0）——**伪装目前仍赚不到什么** |
| **破坏设备** | 每夜一次 | 人类抢修窗口，超时 −5 进度 | 制造 30 秒倒计时压力 | — |
| **拆保安机器人** | 刀数 1（装甲 2 点，需 2 刀） | 解除拘留威胁 | 价值 8 **低于**追人（9/12）→ **有猎物在就不拆**；且要**围攻成立**（≥2 队友 + 共同目标 + 45% 概率） | — |
| **反证（在场反驳）** | 无 | 若我也在现场却没看见 → 指认者反被怀疑 0.16 | 只在**亮房**成立；暗房不算 | `presenceDeny` **4.04/局** |
| **沉默线索** | 无 | 整场不说话 + 健谈 → +0.10 | 只对"白纸"生效（≤1 条旧疑点）；不得升级为准-确证 | `silent` **13.22/局** |

**读法**：现在的对称性是 —— **异形能拿到"确证"的方式变少了（远距只算嫌疑），但能拿到"票"的方式没变少
（构陷 + 带节奏 + 准-确证票权）**；人类的对策变多了（在场反驳、远离、准-确证 friend 挡票）。
所以**误判变多、确证变少**：驱逐准确率 57.9% → 55.5%，夜长压到 75 秒后会议回到 12.1 场/局（不再吃夜晚时间）。

分层约定：**数据（js/data）→ 引擎（js/engine）→ 三域模块（js/t2）→ 编排（js/game.js）→ 入口（js/main.js）→ 主页（js/ui/home.js）→ 复盘（js/ui/replay.js）**。方案 A 按三域切已落地三块：`js/t2/space.js`（空间与资源域常量）、`js/t2/ai.js`（AI 拟人化域认知链读值与时间窗）、`js/t2/decision.js`（玩家决策域报告额度与会议发言解析）；`game.js` 保留编排与薄委托，状态沿用 `_t.G()`。
所有脚本都是有顺序的经典脚本（IIFE + `window.SK*` 命名空间），不使用 ES Module 与构建步骤。

### 3D 预演（独立子项目）

`3d/` 是 2026-11-03 晚新立的 Godot 4.6 垂直切片，用来验证 2.5D 的地图 / 贴图 / 角色能否升维，
以及真正 WASD + 鼠标视角的手感。它不经过 `index.html`，不继承主项目的 `file://` 红线；
地图数据由 `3d/tools/export-map.cjs` 从 `js/data/map.js` 导出。运行方式、复用边界、
实测读数（1 秒 4.2 米、撞墙 1.14 米停住）见 `3d/README.md`，架构见 `3d/ARCHITECTURE.md`。
