# 新返航录

浏览器里的太空船社交推理游戏：**11 名人类 vs 4 名异形**同船实时行动。人类一边修飞船一边猜谁在说谎，异形一边杀人一边把所有人骗过去。

零依赖纯前端，不需要构建，双击 `index.html` 就能玩。

- 2.5D 在线试玩：<https://returnlog.pages.dev>
- 3D 在线试玩：<https://returnlog-3d.pages.dev>
- 3D 源码：<https://github.com/hxj-2888/returnlog/tree/3d>
- 规则权威文本：[docs/CORE_RULES.md](docs/CORE_RULES.md)

**版本**：返航录 V3.7（`package.json` 3.7.0）· 2.5D 主线

---

## 一、这局游戏在干什么

船上共 **15 个席位**：11 人类 + 4 异形。你可以占其中一席（人类或异形），也可以只当观察者。
其余 14 个位置全部由 AI 打——它们**只知道自己看见、听见、查到的东西**，不读身份表，会记错、会怀疑错人、也会撒谎。

一夜 **75 秒**，节奏像这样循环：

```
开局公开讨论 50s（本轮不投票）
  └─ 第 1 夜 75s ── 白天会议 讨论 60s + 投票 5s + 公布 3s
       └─ 第 2 夜 75s ── 白天会议 ……
            └─ 第 10 夜起「终结者时刻」：全场身份公开，每个活人补到 1 发子弹
```

夜里发现尸体按 `R` 报告，开的是**夜晚会议**（讨论 35s + 投票 5s + 公布 3s）；**会议不消耗夜晚时间**，散会后的秒数原样还回去。
天亮瞬间所有濒死者因失血死亡，未修完的故障自动消失且不扣分，然后把全体活人传回中央会议室开会。

## 二、人类怎么赢

1. **把全船维修进度推到 45 分返航**，或者
2. **让 4 名异形全部出局**（死亡或被驱逐）。

具体做法：每人开局分到 **4 个自己的任务点**（1 个高难点 + 3 个普通点，全船 26 个点随机抽，可能和别人重合）。
高难点修好 **+2 分**、普通点 **+1 分**，站桩时长 4~10 秒，可以乱序完成。
个人进度攒到 **3 分**和 **5 分**时各得 1 张「物资申请单」（每人最多 2 张），拿到中央会议室圆桌旁点一下就领。

死了也不完全退出：幽灵可以穿墙继续做任务，但**整局只有 1 分额度**、站桩时间 ×1.6，而且不能修故障、异形幽灵干脆不能修任务。

## 三、异形怎么赢

让 11 名人类**全部死亡或出局**。手里的牌是：

- **刀**：每人每夜 1 把，距离 1.35 格且需要视线；出刀**没有阵营限制**（异形可以互刀）。刀人只造成**濒死**，人还活着、还能被救，天亮才因失血死亡。放倒人后自己有 2 秒 ×1.5 的逃逸加速。
- **破坏**：每夜 1 次，选定舱室后在该舱任务点里随机一个设备起故障。**30 秒内没人修完 → 全船进度 −5 分**；修故障要站桩 10 秒。
- **管道**：全船 8 个管口，只有异形能钻，站在管口 1.6 格内可选任意另一个出口瞬移，冷却 20 秒（玩家和 AI 共用冷却）。
- **撒谎**：见下面「会议」一节。

倒地的人躺在原地就是信息源：**拖尸**（`D`）会拖慢到 2.5 格/秒，而且每 1.6 秒发出一次 8 格内可听见的拖拽声。把尸体拖离医疗间是一条很重的嫌疑。

## 四、信息才是主战场

这套游戏真正的对抗发生在"谁知道什么"这一层，玩家和 AI 用的是**同一套判据**：

- **视野**：同一间亮舱整间可见；同一条亮走廊整条可见；从亮舱看相连走廊需要视线（LOS）。近身圈人类 2.3 格、异形 3.5 格，手电锥 7 格 / 60°。断电时全船只剩会议室亮，走廊灯全熄，监控也断信号。
- **自动门**：默认关闭，活人进 3 格内滑开、离开 3.6 格关闭；**关门同时阻挡移动和视线**；断电期间每扇门要 2 秒扫描才放行。
- **证据权重**（进入嫌疑分，节选）：出刀红身 0.85、出刀 0.75、钻管道 0.70、破坏 0.65、停摆机器人 0.60、枪击 0.55、拘留 0.60、把尸体拖离医疗间 0.45、拉闸 0.32、假装做任务 0.30、拖尸 0.22、放弃任务 0.14；听觉类（尖叫 0.22、刀 0.18、枪 0.16、管道 0.20、拖拽 0.12、断电 0.14）更弱。
- **亲眼确证**要同时满足"异形专属行为 + 距离 ≤ 4.5 格"；隔远了只加嫌疑，不算实锤。
- **人会记错**：目击有 **20%** 概率把确证指向当时看得见的另一个人；说出口的证词有 **22%** 概率记错舱室、**18%** 概率记混动作。听众的注意力只有最近 **10 条**传闻，新的顶掉旧的。
- **口供要能对上时间线**：证词只在对应时间窗内比对，窗口内只要有一条位置记录吻合就成立，全对不上才算矛盾。
- **正向信任**：修好故障 +0.20、救人 +0.16、把伤员拖到医疗间 +0.16、合闸 +0.12、做完任务 +0.12。注意——**假装修任务和真修好，在目击者眼里同价**，因为看到的动作一模一样。信任会抬高被指控的门槛、让别人按概率弃票。
- **情绪**：当众被咬会记仇，当众被保会记恩；`trust ≥ 0.8` 的人直接"不过票"。

### 会议上 AI 会说些什么

发言内容由**真实经历**组句（去过哪间、修过什么、看见谁、目击了什么），不是随机抽台词；同一人连说到第 3 句起自动让位；异形每场会议发言另有硬上限。异形的话术有明确概率：

| 行为 | 触发率 |
|---|---|
| 编造具体伪证（出刀 55% / 钻管道 30% / 开枪 15%） | 有目标时 **85%** |
| 多只异形共同指控同一个人 | 人类占多数时 **55%**，否则 18% |
| 抢先点名好人（先发制人） | 每场 **45%**，且 60% 是全场第一句 |
| 公开指控已认出的队友换信任（大义灭亲） | **20%** |
| 每场会议发言硬上限 | 6 条 |

另有 **22%** 概率整局出现一个"爱指挥"的领袖（可能是异形），听众按「号召力 × 对领袖的信任」决定是否跟。

### 投票

只有**活着且不濒死**的人有票。>7 人时需要 **4 票**、≤7 人时需要 **3 票**，而且**必须是唯一最高票**，否则无人出局。
人类 AI 的投票顺序大致是：亲眼确证 → 被咬狠了按性格反咬 → 自己公开指控过的人 → "基本是异形"的准-确证 → 明确嫌疑人 → 两个假说胶着就弃权 → 按性格弃权 → 有条件跟票（自己手里必须有真凭实据，听说和领袖点名不算）。
投对了 +0.10 信任，投错了 −0.14 信任并 +0.09 嫌疑，带头者效果 ×2.2。

## 五、船上的设施与资源

地图固定：98×94 格、**10 个舱室 + 11 条走廊 + 26 个任务点（其中 8 个高难）+ 8 个管道口**。

| 设施 | 作用 | 关键数值 |
|---|---|---|
| **电闸**（配电室） | 拉闸让全船变暗、断监控、所有门变 2 秒扫描 | 本夜第 1/2/3 次拉闸 3/6/9 秒，第 4 次起恒 9 秒；合闸 4.5 秒，配电室电路修好后降到 3 秒。被人**近距离看见拉闸断电**＝身份级确证 |
| **监控台** | 远程看各舱画面 | 必须站进监控室或监控台 1.8 格内；断电即黑屏 |
| **军械 / 医疗补给点** | 申请单兑换 | 军械花 1 张站桩 5 秒 → 子弹补到 1；医疗花 1 张站桩 3 秒 → 医疗包补到 1；都不叠加 |
| **保安机器人** | 4 点巡逻，目击危险行为就抓人 | 视野 6 格 / 前方 180°；出刀、开枪会被追（破坏不触发）→ 压制 0.9 秒 → 押到军械库拘留 30 秒；每夜最多擒拿 2 次；可被刀砍（2 点装甲）或打停摆 |
| **医疗无人机** | 悬停在医疗间正中，拉起濒死者 | 需在医疗间内、飞近 1.15 格、治疗满 7 秒；每夜 2 次；救起后 3 秒不能移动；可被刀砍（1 点装甲） |
| **管道口** | 异形瞬移网络 | 8 个口任意互达，冷却 20 秒 |

## 六、操作

移动是**点击地面**，其余全在键盘：

| 键 | 作用 | 键 | 作用 |
|---|---|---|---|
| `W` | 交互（多项时开轮盘，数字键选） | `R` | 报告尸体（距离 2.4 格，每人全局 2 次） |
| `A` | 出刀（仅异形） | `B` | 开枪（需 1 发子弹，射程 9 格） |
| `S` | 搜尸 / 查看伤情（站桩 1.2 秒） | `H` | 破坏（仅异形，每夜 1 次） |
| `D` | 拖拽 / 放下身体 | `V` | 监控 |
| `F` | 施救（需医疗包，站桩 5 秒） | `M` | 音效开关 |
| `Esc` | 暂停 | `F2` | DEV 全知视角 |
| `F8` | 帧率仪表（FPS / 绘制耗时 / 帧间隔） | | |

`W` 的交互轮盘覆盖：维修故障、钻管道（异形）、领申请单、补给点兑换、合闸/拉闸、全船监控、搜尸/查看记录、拖尸/放下、报告、施救、维修任务点。
站桩动作一动就打断并清零；**任务点维修、修复故障、拉闸**有小游戏，领单、补给、搜尸、施救不弹。

## 七、14 个 AI 的个体差异从哪来

只有一个来源：**四轴性格**——激进 / 谨慎 / 社交 / 好奇。每局随机，三档 28 / 50 / 72，概率 30% / 40% / 30%，再统一乘一个压缩系数 0.45。
它决定的是这些具体数字：人类开枪门槛 0.36（激进）~0.60（谨慎）、投票弃权率 0.18~0.70、异形出刀距离、扑向"正在做事的人"的偏好、搜尸意愿、替人辩护和跟票的倾向、记仇与记恩的强度。
异形还有一条性格轴上的"胆量保底"（激进 ≥ 60），否则人类敢投票会把异形胜率压到没法看。

## 八、本地运行

零依赖静态页面，**没有构建步骤**：

1. 直接双击 `index.html`（`file://` 就能跑），或
2. 在目录下 `python -m http.server 8000`，访问 <http://localhost:8000>。

首次进入会加载整船地图、角色与音频，进度条显示「图像 x/y · 音频 x/y」，全部就绪后才开放「进入舱段」；加载失败可点「重试」。

## 九、代码结构

前端 24 个模块，全部用经典 `<script>` 按依赖顺序在 [index.html](index.html) 里加载——**这个文件就是唯一的加载清单**，禁止在别处动态注入脚本。

```
index.html          唯一加载清单 + 关键 CSS
js/config/          版本真源
js/data/            map（舱室/走廊/任务点/管道）、plates、names、lines（语料）
js/engine/          clock、invariants、geo（几何与寻路）、assets、body
js/ai/              sanity（认知/嫌疑/信任/数值真源）、traits（性格系数）
js/t2/              space（移动/门/视野）、ai、decision、minigame
js/scene/           const、crew、shell
js/ui/              home、replay、templates
js/game.js          对局编排
js/main.js          入口
assets/ audio/      运行素材 + MANIFEST / 许可 / 署名
```

两条硬约束：**运行时 0 第三方依赖**，以及**数值、语料、地图只有一处真源**（集中在 `js/ai/sanity.js`、`js/data/map.js`、`js/data/lines.js` 等），UI 层不许复制第二份定义。

## 十、3D 版

- 在线试玩：<https://returnlog-3d.pages.dev>（源码见 `3d` 分支）
- Godot 4.6 Web 导出，3D 垂直切片与预演；首次打开需下载约 169 MB（`index.pck` 132 MB + `index.wasm` 37.7 MB），建议桌面浏览器。
