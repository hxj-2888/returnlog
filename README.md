# 新返航录 3D 版

> **3D 版本**：`V0.1`（`0.1.0`，真源 `3d/version.json`） · **规则移植基线**：`返航录 V1.0`
> **引擎**：Godot 4.6 stable（GL Compatibility） · **在线试玩**：https://returnlog-3d.pages.dev

《新返航录 3D 版》是一款基于 **Godot 4.6** 打造的**第一人称 3D 单机深空太空船社会推理与生存对抗游戏**。
本作是《新返航录》2.5D 版的 3D 延伸实现：除第一人称视角、3D 写实舱室美术与键鼠操控外，全部规则语义、数值参数、AI 认知推理、会议发言与投票追责均与 2.5D 主线保持单一真源同源。

---

## 一、游戏玩法概述

### 1. 阵营与胜负
15 名船员（玩家 + 14 名全自主 AI，亦可自由选择人类、内鬼或旁观者席位，并支持主页自定义 15 人名单）困在同一艘故障频发的返航飞船中展开昼夜博弈：

- **经典局（默认）**：12 名人类 vs 3 名内鬼（内鬼开局互认）。
- **单人局 / 盲鬼局**：11 名人类 vs 4 名内鬼（内鬼互不相识，需靠观察暗夜行为推断同族）。
- **人类胜利**：协作完成全船各舱室的维修任务，将**全船维修进度推至 48 分**，或在会议/战斗中淘汰全部内鬼。
- **内鬼胜利**：在暗夜出刀、制造故障或借会议误导驱逐，令全部人类出局。

### 2. 昼夜循环与核心机制
- **开局公开讨论**：全员于中央会议室核对分工后进入第 1 夜。
- **75 秒暗夜实时行动**：
  - **维修与任务**：每名船员分配 4 项专属舱室任务（含高难 2 分 / 普通 1 分），通过交互小游戏推进进度；幽灵状态下仍可穿墙协助完成限定额度任务。
  - **资源与设施**：累计个人维修进度获得物资申请单，回中央会议室圆桌领取后，可在军械库/医疗间补给点兑换**子弹**与**医疗包**。全船配备 10 大主题舱室、自动感应门、电闸断电系统、监控室全船摄像头、9 处内鬼专用管道、巡逻抓捕现行的**保安机器人**以及驻守医疗间的**医疗无人机**。
  - **暗夜对抗**：出刀/开枪会将目标击倒为**濒死**（天亮失血死亡），期间可拖拽藏尸、搜尸取证并拾取遗留物资、使用医疗包施救，或拉响报告召开紧急会议；出刀后会短暂留下可被目击的红身痕迹。
  - **破坏与终结者时刻**：内鬼每夜可对舱室设备发动限时 30 秒的致命破坏（超时未修扣全船 5 分），或拉闸令全船陷入断电黑暗与应急红光；战局拖至第 9 夜将触发**终结者时刻**，全场身份公开、取消会议并补发弹药展开终极决战。
- **全员会议、发言推理与投票驱逐**：
  - 发现尸体/伤员（夜会）或天亮结算（白会）后全员开会，进入 **讨论 → 投票 → 公布** 三阶段。
  - 玩家可使用 13 类快捷证据模板（指控、作证、带节奏质疑、目击出刀/红光/钻管道/拉闸/破坏等）或自由输入中文台词参与博弈，支持讨论期先投改票、弃权与带头追责。

### 3. 全自主认知 AI（零全知作弊）
- 所有 AI 严格遵循与玩家平等的视野、听觉与行动规则，**绝不偷看系统阵营表**。
- 每个 AI 独立维护基于 **个人信任分（T）与个人情绪分（E）** 的认知模型，结合亲眼目击、听觉定位、时间线不在场证明拆谎、传闻衰减、性格四轴（激进/谨慎/社交/好奇）、领袖号召、内鬼伪装/构陷与带错节奏追责，形成自然且高变数的社会推理体验。

### 4. 3D 沉浸表现
- **写实工业风 PBR 与分舱光影**：全船 10 舱室法线/粗糙度贴图、结构肋柱与踢脚线细节、按舱室主题分层的工业色温与大舱多灯位、近距实时动态阴影、断电脉冲应急红光与手电体积光锥。
- **第一人称战斗与动作反馈**：第一人称战术匕首与手枪模型、刀光拖尾、视觉顿帧、弹簧震屏、3D 刀者红身、定向血雾与血泊贴花、弹道光束、机器人电弧火花、动态描边准星、分级命中确认与 3D 空间音效。
- **局内 HUD 与蓝图回放**：顶部紧凑状态条、左上角自适应任务卡、右上角融合朝向小地图、底部站桩/拖拽/冷却提示条、2 列免滚动会议投票面板以及带整船蓝图坐标轨迹的时间轴复盘器。

## 二、按键操作（默认键位）

| 按键 | 功能 | 按键 | 功能 |
|---|---|---|---|
| `W / A / S / D` | 第一人称移动 | `鼠标移动` | 视角控制 |
| `E` | 交互 / 做任务（多项打开轮盘，`1-9` 直选） | `鼠标左键` | 出刀（内鬼，每夜 1 次） |
| `B` / `鼠标右键` | 开枪（需子弹） | `F` | 施救濒死船员（需医疗包） |
| `R` | 报告尸体 / 伤员 | `G` | 拖拽 / 放下身体 |
| `Q` | 钻管道（内鬼） | `H` | 发动舱室破坏（内鬼） |
| `V` | 打开全船监控（监控室） | `M` | 静音切换 |
| `Esc` | 暂停 / 关闭当前面板 / 释放鼠标 | `P` | 打开设置面板 |

> 键位单一真源位于 `3d/preview/project.godot` 的 `InputMap`。

## 三、快速运行

```powershell
# 1) 首次导入资源（需要 Godot 4.6）
godot --headless --path 3d/preview --editor --quit

# 2) 启动游戏（1280x720）
godot --path 3d/preview --resolution 1280x720

# 3) 运行核心门禁与规则校验
npm run baseline:check
npm run file:check
npm run audit:rules
npm run 3d:assets
npm run 3d:floor:check
```

## 四、仓库结构

| 路径 | 说明 |
|---|---|
| `3d/preview/` | **3D 运行时主体**（Godot 4.6 工程：`scenes/`、`scripts/sim/`、`scripts/ui/`、`scripts/view/`、`scripts/minigame/`、`data/`、`assets/`） |
| `3d/tools/` | 2.5D → 3D 数据导出、PBR 贴图管线、模型同步与一致性校验脚本 |
| `3d/spec/` | 数据契约、资产清单、移植映射账本与文件行数预算 |
| `3d/ARCHITECTURE.md` / `3d/CORE_RULES.md` | 3D 架构边界与自然语言核心玩法规则 |
| `js/`、`assets/`、`audio/`、`tools/`、`index.html` | 随仓携带的 **2.5D 只读基线镜像**（规则、数值、语料与地图真源，供导出与对账） |
