# AI 引擎释义（2.5D 现行实现）

> **这份文档是什么**：把 2.5D 现行实现里的 AI 决策结构，抽成人能读的自然语言。
> 它的用途是**移植参照**——3D 版 AI 行为不对时，拿它对照"2.5D 在这里是怎么决定的"。
>
> **它不是什么**：
> - 不是新的规则原本。`docs/CORE_RULES.md` 仍是最高裁定；本文与它冲突时以它为准。
> - 不新增玩法规则。本文只描述实现口径，不改设计。
> - 不是正确性裁判。2.5D 本身也可能有 bug（`tests/flaky-assertions.txt` 有已登记抖动，
>   `CHANGELOG` 有已修缺陷）。发现某处实现可疑时，**由设计者裁定**，本文跟随实现更新，
>   不得反过来用本文去论证设计该是什么。
>
> **为什么需要它**：`CORE_RULES.md` 覆盖的是玩家能感知的结果（视野、伤害、投票顺序、
> 性格系数），**没有覆盖 AI 怎么选目标、怎么算分**。所以 `ai_alien.gd:_decide`、
> `ai_human.gd` 的决策链在规则里没有任何条目可锚定——行为不对时只能靠玩出来。
> 本文补的就是这一层。涉及条目：`R11.1`（认知来源）、`R14.3`/`R14.7`（投票）、
> `R15`（性格系数），其余属实现。
>
> **来源**：`js/game.js`、`js/ai/traits.js`、`js/ai/sanity.js`、`js/t2/decision.js`（2026-11-14 读数，
> 逐段标行号）。行号会随真源变动，改动后请对照最新源码复核。

## 1. 通用决策骨架

每帧对每个 AI 调一次 `aiHuman`（`js/game.js:2807`）或 `aiAlien`（`js/game.js:3745`）。两者开头相同：

1. 会议中 / 对局结束 → 直接返回（`G.meet||G.over`）。
2. 被保安拘留（`detained`）→ 返回。
3. `dropStaleFix`：手头的抢修目标若已失效则丢弃。
4. **站桩中（`doing>0`）优先递减**，归零后 `finishDoing` 结算。
   - 人类在做任务时若受威胁，会先 `fleeTask` 逃跑，而不是硬扛。
5. 开局错峰 `_delay`：随机小概率走向随机房间，避免 15 人同一秒冲向任务点。
   异形的概率更低（0.35/s vs 人类的 0.45/s），且同样受性格 `delayScale` 缩放。

**这条顺序本身就是规则**：站桩 > 逃跑 > 救援 > 开枪 > 修故障 > 做任务。
3D 若把「做任务」提到「救濒死」之前，玩起来就是"见死不救"。

| H2 | 有医疗包，7.5 格内有濒死者且无人正在救 | 走到 1.7 格内站桩 `STAND.revive` 施救 | 2852 |

### 2.1 人类开枪的判定（H3）

```
阈值 thr = SKTrait.C.shootSus(a)          // 0.50 − 0.14·b(aggr) + 0.10·b(caut)  → 0.36~0.60
若目标"基本确定是异形"  thr ×= ALMOST.foeShootMul      // 更敢打
若目标"基本是好人"      thr ×= 1.4                      // 更舍不得打
夜间用存量嫌疑时再打 0.7 折
```

- **射程与玩家共用** `SKSanity.SHOT.range`——射程是能力，不是意愿。
- 追击距离：已确证 → `chaseKnown`；仅有嫌疑 → `chaseSus`。
- 开枪后 `_rest = 2.5~4.5 秒`（不会连射）。
- 目标若是队友（`isMate`），异形侧会排除；人类侧靠嫌疑分把关。

## 3. 异形 AI：主循环 + 效用表

### 3.1 主循环顺序（`aiAlien`，`js/game.js:3745`）

| # | 条件 | 行为 |
|---|---|---|
| A1 | 站桩中 | 递减；若是**假动作**（`_doing==='fake'`）结束 → 进冷却 `DISGUISE.cooldown` 并广播信誉（`fakeRepair` / `fakeWork`，两种 kind 分别记） |
| A2 | 开局错峰 `_delay` | 同人类，概率 0.35/s |
| A3 | 有"重返现场报案"计划 `_reportPlan` | 先离开做不在场，几秒后回尸体旁；**四周无人时先摸走物资**再拉铃；额度或场次不够则放弃 |
| A4 | 刚杀完人未决定是否演报案 | 每具尸体只掷一次骰：**有活人目击 15% / 无人看见 40%** 决定演"发现者" |
| A5 | 有队友濒死 | `alienMateRevive` 优先救 |
| A6 | 选猎物 | 排除队友；优先"正在站桩做事的人"；被目击时的惩罚见 §5 |
| A7 | 有子弹且目标不在刀程 | 开枪（不打队友） |
| A8 | 保安视线规避计时 | 先躲开 |
| A9 | 每 0.5 秒重算计划 | `alienPlan`（§3.2），取最高分执行 |

> 计划重算用 0.5 秒 CD，**不用事件时钟**：批量模拟/暂停时模拟时钟不走，
> 用 `evNow()` 差值恒为 0，计划会永不重算（实测踩过）。

### 3.2 效用表（`alienPlan`，`js/game.js:3405-3535`）

公共项：
```
left = clamp(G.t / NIGHT, 0.25, 1)      // 夜越往后，主动行为的价值越低
walk(d) = d / moveSpeed(a)              // 距离折算成秒
```

| 计划 | 分数 | 前置条件 |
|---|---|---|
| 拉闸 `breaker` | `14 · left − breakerOffTime()·1.5 − walk(距离)` | 有闸、当前未断电、`sabUsed` 未用、本夜没被跳过 |
| 破坏 `sabotage` | `8 · left − walk(距离) − 1`；配电室未断电再 `−4` | `sabUsed` 未用；跳过"刚因有人看着而放弃"的舱室 8 秒 |
| 拆机器人 `bot` | `8 · left − walk(距离)` | 刀 > 0；保安机器人还需 `secbotRaidOk`（围攻成立） |
| 出刀 `chase` | `td < knifeReach` → **12**；`td < 5` → **9**；否则 **2** | 刀 > 0 **且**开夜封锁结束（`knifeLockLeft()<=0`）；否则恒为 0 |
| 伪装 `disguise` | `DISGUISE.planValue · disguiseScore − walk(距离)` | 非贴脸可杀、`_fakeCD<=0`、无支援目标、未拖尸、有观众 |

取 `max`。平局顺序：伪装 → 出刀 → 拆机器人 → 拉闸 → 破坏。

**几条被历史裁定钉死的边界**（改前必须确认，都是踩过坑的）：

- **出刀分数必须压过跑图类行为**：贴脸 12、可追 9。否则异形会当着猎物拆设备。
- **刀用完 `chase` 必须归零**：旧版恒为 12，而拉闸上限 9.5、破坏上限 7.0，
  于是"刀没了"的异形整夜只游荡——效用表被一个常数架空。
- **贴脸能杀时不演**：伪装进同一张表后，加权观众会把分数抬过 12，异形会放着人不杀去站桩。
- **当众合闸是小概率通道**：每只异形每夜掷一次（`DISGUISE.breakerChance`），
  仅当断电、有观众、闸可达、且当前没有更值的计划（`best ≤ max(chase, 6)`）时触发。
  它是**真合闸**（灯会亮、吃 `breakerLoss`），不是免费的 +cred。

### 3.3 执行前的理智线

拉闸/破坏出手前还要过三道，任一命中即**本夜放弃**（不是折算概率）：

```
目击者数 ≥ BREAKER.witnessCap
隐蔽度   < BREAKER.minConceal
周围人数 ≥ BREAKER.crowdN
```

这是 2026-11-01 的口径：把"站桩越久越谨慎"这种概率折算删掉，改成硬条件。

## 4. 团队量化表 `SKTeam`（`js/ai/traits.js:126`）

| 键 | 值 | 作用 |
|---|---|---|
| `FIX_CREW_CAP` | **3** | 同一故障已有 3 人在赶/在修 → 边际收益为负，转去做任务（防踩踏） |
| `BOT_SEC_VALUE` | **8** | 拆保安机器人；**低于**贴脸出刀 12 与可追 9，所以身边有猎物时不去拆 |
| `BOT_MED_VALUE` | **8** | 拆医疗无人机（挡救援，价值独立） |
| `BREAKER_VALUE` | **14** | 拉闸的团队价值 > 一次破坏（8），否则"1 秒下手"的破坏永远挤掉要站 4.5 秒的拉闸 |
| `SABOTAGE_VALUE` | **8** | 破坏 = 牵制（把人类钉在修复上 10~20 秒），被修掉牵制也已发生 |

## 5. 性格系数 `SKTrait`（`js/ai/traits.js:33-120`）

四轴：`aggr` 激进 / `caut` 谨慎 / `soc` 社交 / `cur` 好奇。
中性档 50，档位分布 `[[28, 0.30], [50, 0.40], [72, 0.30]]`，
全部差异再乘全局压缩 `TRAIT_GAIN = 0.45`（`R1.8`）。

| 系数 | 公式 | 含义 |
|---|---|---|
| `knifeWatcherPenalty` | `12 · (1 − 0.55·b(aggr) + 0.45·b(caut))` | 有目击者时的出刀惩罚（基线 12 格） |
| `knifeBusyBonus` | `−12 · (1 + 0.35·b(aggr))` | 优先砍"正在站桩做事的人" |
| `knifeReach` | `1.3 · (1 + 0.22·b(aggr))` | 贴脸出刀距离门槛 |
| `knifeBold` | `0.50 ± 0.16`，夹在 `[0.30, 0.72]` | 有目击仍出手的胆量 |
| `knifeWatcherCap` | 取 `KNIFE.witnessCap`，**性格不改** | 3 人看见就一定放弃（理智线，非性格） |
| `shootSus` | `0.50 − 0.14·b(aggr) + 0.10·b(caut)` | 开枪所需嫌疑分 |
| `voteAbstain` | `0.52 − 0.34·b(aggr) + 0.18·b(caut)` | 弃权率 |
| `delayScale` | `1 − 0.45·b(aggr) + 0.30·b(caut)` | 开局错峰缩放 |
| `fleeThreshold` | `1 + 0.60·b(aggr)` | 危险里多站一会儿的阈值 |
| `lootScale` | `1 + 0.70·b(cur)` | 搜尸/看一眼的意愿 |

> `voteAbstain` 有反直觉记录：2026-11-02 试过从 0.52 回落到 0.44，结果人类**反而更准**
> （票多 → 证据被更多票兑现）。弃权率高不是"冤枉"的来源。
