## 二、AI 推理（A）

### A1 信任分 T 的轴向与锁定（已按用户纠正）

| 选项 | 内容 | 结果 |
|---|---|---|
| **a（最终）** | `T ∈ [−1, +1]` 双极轴：`+1` 完全信任、`0` 中立、`−1` 确认异形并锁死 | **a** |
| b | `T ∈ [−0.5, +0.5]` | 中间版本，已废弃 |
| c | `T ∈ [0, 1]` 概率轴 | 最初版本，已废弃 |

**拍板**：用户 2026-11-19 最终定 `±1`。这是把既有 `cred` ±0.5 刻度整体放大 2 倍，
**所有加减分权重与阈值同步 ×2**，语义位移与 ±0.5 版一致。正轴记可信行为，
负轴记可疑/伪装行为，近距离目击异形专属行为直接钉到 `−1` 并锁死。
**起始值**：`T0 = 2 × identityPrior − 1`（人类占多数时约 `+0.46`），`0` 是 50/50，不是开局默认。
**影响**：整个模型的符号约定；定了不再改。

### A12 人类 AI 徘徊（用户现场指出）

**现象**：人类 AI 有时忽然跑到角落，再走回来。

**根因**（`js/game.js#aiIdleRoam`）：
1. 空闲时若没有故障 / 申请单 / 可信同伴 / 要躲的人，就走
   `const r = M.rooms[Math.floor(Math.random()*M.rooms.length)]; randIn(r)`——
   `randIn` 在房间**矩形内均匀取点**，不排除贴墙与角落；
2. 到达后**没有停留时间**：下一帧 `!a.path` 就再抽一个房间，于是"角落 → 另一个角落"。
3. 抽的是**全船随机房间**，不看距离，经常跨半张图来回走。

| 选项 | 内容 | 建议 |
|---|---|---|
| **a（建议）** | 空闲锚点 + 到达停留 + 就近优先 | **a** |
| b | 只给 `randIn` 加贴墙余量，其他不动 |  |
| c | 不改 |  |

**建议 a 的三步**：
1. `idleSpotIn(r)`：离墙 ≥2 格、排除角落、优先房间中心/桌边/终端等"像人待的地方"；
2. `a._idleT` 到达后停留 4~9 秒（按性格缩放），停留期间不重抽、只播 idle 动作；
3. 选房间时优先当前舱 / 相邻舱，只有"附近没人且无危险"才跨图；躲人时给**就近安全点**，
   不再给随机角落。

**验收**：`node tools/track-ai.cjs --sessions 6 --sec 120` 对比改前改后：
空闲移动总距离与"贴墙/角落取点"次数下降 ≥50%，无新增卡死；门禁全绿。
**影响**：只改走位，不改任何判据与分数。
