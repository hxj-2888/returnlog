## 3. 资产复用判定

| 资产 | 判定 | 说明 |
|---|---|---|
| `js/data/map.js` | **可直接复用** | 房间 poly / 走廊 pts / walls / cover / points 都能升维 |
| `assets/scene/v4/tex/*.png` | **可直接复用** | 地板、墙面、金属、桌面材质表现良好；正式版需补法线/粗糙度 |
| `assets/scene/crew/crew-*.png` | **先 billboard** | 4×5 帧、96×160/帧；近看会纸片化 |
| `assets/scene/cozy` 家具 | **只适合 billboard/贴花** | 32×32 俯视图不是 3D 模型 |
| `assets/scene/v4/base-lit.png` | **不可直接用** | 俯视烘焙底图，3D 要重新打光 |
| `js/game.js` | **不可直接搬** | DOM/Canvas 2D 编排；规则、数值、事件 schema 可复用 |
| `js/ai/sanity.js` / `js/data/lines.js` | **可数据化复用** | 导出 JSON 给 3D 模拟核心 |

## 4. 引擎结论

**Godot 4.6 是这台机器上最合适的 3D 运行时。**

- 原生 `CharacterBody3D` / `NavigationAgent3D` / Control UI，WASD 与 3D 碰撞都是现成的；
- 便携版 79MB，不装进系统、不改 PATH；
- Blender 只做资产管线，不承担运行时；
- Three.js 虽然能复用 JS，但会把项目继续绑在 DOM/浏览器，不适合这次「重新立一个小项目」的方向。

## 6. Qwen-Image 下载

- 选择：`city96/Qwen-Image-gguf` 的 **Q3_K_S**（8.95GB），配

  （UD-Q4_K_XL 5.15GB）+ VAE 0.68GB，约 10.02GB，明显更适合 8GB 显存。
