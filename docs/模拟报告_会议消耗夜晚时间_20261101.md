## 一、改了什么

`js/game.js` · `finishMeeting()`

```diff
- nightLeft = Math.max(8000, m.remainMs - elapsed);   // 8 秒保底，有不动点
+ nightLeft = m.remainMs - elapsed;                  // 允许扣成负数
...
+ if(nightLeft <= 0){
+   G._overtime = true; dawn();                       // 会议把这一夜耗光 → 直接天亮
+   G._overtime = false;
+ }
```

顺带给天亮会议的副标题加了一句「上一场会议拖到了天亮」，让玩家知道为什么突然跳天。

## 四、怎么读这张表

### 1. 夜数和会议数**降了**，这是修复的直接结果

旧版 8 秒保底会让一夜被切成很多小段：开会 → 8 秒 → 又有人报尸体 → 再开 → 又 8 秒。
每一小段都是一个"夜"，也都能再开一次会。所以旧版的 `nights 5.76 / meetings 13.7` 里，
有相当一部分是**碎片化的伪夜**。

修复后一次深夜会议直接把夜晚推到天亮，碎片消失 → `nights −5.2%`、`meetings −8.8%`。

**这正是你要的行为**：不会再出现"还剩 10 秒 → 开个会 → 还是 8 秒 → 再开个会 → 还是 8 秒"。

### 2. 出刀和破坏也降了

`knives 10.275 → 9.685`、`sabotages 10.857 → 10.310`。
旧版靠"无限续夜"实际上给异形塞了更多夜间行动窗口；夜不再被拉长，异形的窗口就回到正常长度。

### 3. 人类为什么反而多赢了 1.75pp

不是"人类变强"，而是**局面形状变了导致的统计重排**：异形出局的局从 95 涨到 122。
可能的原因是夜被切得更"整"以后，尸体报告的时间分布更集中在夜里前段，
目击者（而不是"深夜最后 8 秒里乱作一团"）更容易把线索串起来。

这一条**没有直接证据**，只是对数字的合理解释；样本 400 局，单项 ±5pp 的噪声足以吞掉它。
如果要确认，得做 1000 局 + 分时段统计，这一批没做。

### 4. 一个反直觉的点：任务进度只掉了 2.8%，但"维修达成"少了 17%

因为 `prog` 是**局末累计值**，被"人类全灭"的局拉低；而"维修达成"要求跑到 45 分。
碎片夜消失后，人类的总有效时间略降（`nights −5.2%`），跨过 45 分的局就少了 20 个。
也就是说：**修复对人类是轻微不利的**，只是这点不利被其他噪声盖住了。

## 五、结论

1. **修复按预期生效**：门禁新增 3 条断言（582 通过 / 0 失败），
   「夜晚剩 90 秒开会 30 秒 → 剩 60 秒」「夜晚剩 10 秒开会 30 秒 → 直接天亮」「天亮散会 → 天数 +1、时间回满」全部通过。
2. **平衡没被破坏**：人类 53.25% → 55.0%，落在噪声区间内。
3. **副作用是可解释的、也是想要的**：碎片夜消失 → 夜数和会议数下降 → 异形的"续夜红利"消失。
4. 如果后续想把这 17% 的"维修达成"损失补回来，最直接的旋钮是
   `NIGHT`（120 秒）或任务点分值，**不是**再去动会议结算。
