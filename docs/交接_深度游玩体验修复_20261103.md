## 2. 修复清单

### T1【P0】尸检/伤情卡片会静默偷走夜晚时间

**现象**
`loop()`（`js/game.js:2108` 附近）在 `G.inspect`（尸检卡片）时跳过 `update()`，世界冻结；
但夜晚时钟是真实时间（`SKClock` 的 `endsAt`），**关闭卡片时没有任何补偿**。
对比：暂停面板 `togglePause()`（`js/game.js:586`）在恢复时会把 `G.phase.startedAt/endsAt` 平移暂停时长。

**证据（可复现）**
1120×700、开局会后约 72.5 秒时，直接置 `G.inspect={agent:v}` 冻结 3 秒再清空：

```
打开 inspect 冻结 3 秒 → 恢复后 0.3 秒内 G.t 从 72.5 掉到 69.2（-3.32s）
```

四局人类局的夜长损耗（72.9 / 64.2 / 56.8 秒 vs 75 秒）与这个方向一致。

**期望**
卡片打开期间夜钟冻结；关闭后余时与打开时一致。

**实现提示**
- `openBodyCard()`（`js/game.js:7347`）里记 `G.inspect.openedAt = performance.now()`。
- `closeBodyCard()`（`js/game.js:7376`，**全仓唯一**的 `G.inspect=null` 点）里：
  ```js
  const d = (G.inspect && G.inspect.openedAt != null) ? (performance.now() - G.inspect.openedAt) : 0;
  if (d > 0 && G.phase && G.t > 0) { G.phase.startedAt += d; G.phase.endsAt += d; }
  ```
  与 `togglePause` 完全同一套补偿，别新造计时器。
- 注意：`G.inspect` 在 `endGame()` 里也会被 `closeBodyCard()` 关闭（此时对局已结束，补偿无意义但无害）。
- 不要改 `loop()` 的冻结条件本身（会把世界动起来）。

**验收**
- 建议顺手给 `_t` **新增**（只增不改，门禁契约允许）两个方法：
  `openBody:(i)=>{const b=G.agents[i];if(b&&bodyPos(b))openBodyCard(b);return !!G.inspect;}`、
  `closeBody:()=>closeBodyCard()`。
  门禁用例：夜间 `_t.openBody(i)` → 等 3 秒 → `_t.closeBody()` → `G.t` 的减少量 ≤ 0.5 秒。
- **探针别直接置 `G.inspect=null`**：那会绕过补偿逻辑，测出来永远是"没修好"（见 §8 的正确写法）。
- 手工：开局 → 入夜 → 走到一具尸体旁按 W 打开卡片停留 5 秒 → 再按 W 关闭，HUD"剩余 X 秒"几乎不变。

**风险**
低。唯一要小心的是别和暂停面板的补偿叠加（两者不会同时成立：`togglePause` 在 `G.inspect` 时直接 return）。

### T3【P1】旁观/DEV 顶栏盖住会议标题与结算标题

**现象**
DEV 横栏 `#dev`（`js/ui/templates.js:218`）固定贴顶，实测占 **0~134px**；
会议标题 `#m-title` 在 **72~102px**、副标题 106~146px ⇒ 标题被完全盖住；
结算页 `#end .card` 的标题同样被盖。
`syncDevUi()`（`js/game.js:484`）已经为 `#hud` 做了让位，但**没有处理会议/结算覆盖层**。

**证据**
`research/shots/s1_meet3_talk.png`（旁观会议，标题不可见）、`research/shots/s1_end.png`（结算标题被盖）。

**期望**
DEV 开启（旁观 / `?dev`）时，会议卡片与结算卡片整体下移，标题可见；DEV 关闭时恢复。

**实现提示**
- 在 `syncDevUi()` 里量出 `dev.offsetHeight`（那里已经在量，见 500~510 行的 `#hud` 让位逻辑），
  顺手设置：
  ```js
  const off = on ? dev.offsetHeight : 0;
  const mtg = document.querySelector('#meet .mtg');
  if (mtg) mtg.style.marginTop = off ? off + 'px' : '';
  const endCard = document.querySelector('#end .card');
  if (endCard) endCard.style.marginTop = off ? off + 'px' : '';
  ```
- 打开会议（`openMeeting`）与结算（`endGame`，`js/game.js:4648`）时各调一次 `syncDevUi()`，保证量到的高度生效。
- `#meet` 的 `.mtg` 是 flex 居中容器里的子元素，加 `margin-top` 会把它推下去；如果发现被压扁，
  改用 `padding-top` 或 `transform:translateY()`，但要保证小屏（844×390）不出滚动条。
- 不要用 CSS `#dev:not(.hide) ~ #meet .mtg` 这种兄弟选择器（依赖 DOM 顺序，易碎）。

**验收**
- 门禁新增（旁观局）：会议打开时 `#m-title` 的 `rect.top >= #dev` 的 `rect.bottom`。
- 手工：旁观开局会 + 结束页截图各一张。

**风险**
中低。DEV 栏高度在窄屏会变（媒体查询把 15 张卡从 8 列变 5/3 列）；用运行时 `offsetHeight`，别写死 134。

### T6【P2·可选】模板默认对象是"02 银翼"，手快点「怀疑」会误指控

**现象**
`syncMeetTemplates()`（`js/game.js:6232`）默认 `selectedIndex=0`（第一个活着的 AI）。

**期望**
默认显示占位「— 选择对象 —」（`value=''`）；未选对象时点需要对象的模板 → `toast('先选对象')`，不发言。

**实现提示**
- 在 `sel.innerHTML=''` 之后先塞一个 `option[value='']`（文案「— 选择对象 —」），
  无历史选择时选中它（不要 `selectedIndex=0`）。
- **坑**：点击处理在 `js/game.js:9700-9707`，`const ti=+(sel.value)`，空字符串会变成 **0 = 玩家自己**，
  会生成"我怀疑01 星尘"。必须在 `+` 之前判断：
  ```js
  const rawT=document.getElementById('m-tpl-target').value;
  if(!rawT && b.dataset.tpl!=='where' && b.dataset.tpl!=='deny'){toast('先选对象');return;}
  const ti=rawT?+rawT:-1;
  ```
  `meetTemplateText` 已经对无对象返回 `''`（`js/game.js:6219`），所以不选对象不会再发出怪句。
- 门禁里有与「模板 / parseSpeech」相关的用例（在 `tools/test-v3.cjs` 里 grep「模板」），多数显式设置目标；改完必须全量跑。
  若发现回归面太大，本项可以延后，T1–T5 优先。

**验收**
新增断言：未选对象点「怀疑」→ `#m-say` 不新增玩家行，且出现 toast（读 `#tip`/`G.msg` 任一即可）。
