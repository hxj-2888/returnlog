## 4. 标准改动流程（照做，别跳步）

1. **先跑基线**：`npm test`，把「X 通过 / Y 失败」记下来。**不许沿用旧读数。**
2. **一次只改一类**：逻辑、数值、文案分开改，保持可归因；混改会让门禁失败无法定位。
3. **改完立刻跑门禁**：失败一律按回归处理，先回滚或修好，不带 FAIL 提交。
4. **数值改动额外跑模拟**：`npm run sim`，对比 `tools/mc-report.md` 的胜率与机制触达率；只在粗粒度总量上比较（见 §7.2）。
5. **更新 `CHANGELOG.md`**，固定三段：**本批改动 → 读数变化 → 下一批立项依据（用户裁定后填）**。历史条目只标注不删除。
6. **提交**：`type(scope): 摘要`（feat / fix / docs / chore），中文；推送 `origin` 与 `gitee` 两端，确认三端 HEAD 一致。
7. **若调整改变了架构归属或真源**：同步 `ARCHITECTURE.md` §10 与 `docs/_planned/03-方案A-按三域切施工单.md` 的进度表，不要留两套口径。

## 5. 语料调整（`js/data/lines.js`）的硬约束

> 只有调整台词时才需要看；改玩法可跳过。

- **结构**：按六类说服策略分池（identity / accuse / defend / evidence / ask / call / confront 等），每类分 `hot` / `cold` 两档，另有 `combo` 组合式与 `WHY` 证据短语。
- **长度**：渲染口径 **8~22 汉字**；`_clause` 结尾 2~14；`LONG_OK` 里的类别可到 26。
- **槽位**：只允许 `{n}{t}{r}{r2}{u}{k}{when}{why}{prev}`，或 `{a|b|c}` 交替写法；**单值花括号 `{上次}` 会被判 FAIL**。
- **必备槽**：`accuse` / `endorse` / `confront` / `almost` 必须带 `{t}`；`identity` / `selfcite` 必须带 `{r}`；`challenge_player` 必须 `{u}{r}{r2}`；`known_accuse_hard` 必须 `{t}{r}` 且含「异形」。
- **条数下限**：主要类别 ≥24；`endorse` ≥8、`leader_refuse` ≥6、`selfcite` ≥8；其余 ≥5。
- **写作纪律**（文件头部原文）：短、口语、不用书面词（不写"时间线/证据链/嫌疑人"）、允许半句、不写脏话。
- **体检**：`node tools/lines-audit.cjs --strict` → 当前 **1400 通过 / 0 失败 / 118 提示**。
- **真源依赖**：`lines-audit.cjs` 的自述正则与舱室词表**从 `js/t2/decision.js` 读**（第三批改造）；若改 `parseSpeech` 的写法，必须同批改体检工具的读取逻辑，**不要在工具里另抄一份表**。

## 7. 已知坑（重构后新增 + 老坑，按踩中概率排序）

1. **热路径不要写 `SKT2X.fn(...)` 命名空间直调。** 收敛时实测：跨 script 全局属性查找拖低帧率，旁观者断言从 4.4 格掉到 2.4/2.8 格。正解是 IIFE 顶部的**局部别名**（已在位 51 个）；新增 T2 函数也按这个模式接，不要新建薄委托函数。
2. **同 seed ≠ 同随机路径。** `monte-carlo.cjs:276` 原文：任何新增一次随机调用都会把后面整条随机流挪位。**逐局 / 逐格差值不能归因**；跨批只比粗粒度总量（胜率、夜数、会议数、驱逐数），单机制次数要换 seed 各跑一批看摆动。
3. **门禁时序敏感。** 「旁观者点击直线飞行」阈值 `dist > 3`、只等 900 ms 墙钟；收敛后约半数实跑会掉到 3.0 格上下。**先原样复跑**；要根治应改确定性步进（`simT` / 固定 dt），**不要调阈值**。
4. **`file://` 下亮度四态不可读。** 底图跨域导致 canvas taint，`ux-audit.cjs` 的 U6 会跳过；要测亮度先 `npm start` 起 5173 再用 http 入口。
5. **`_t` 是门禁契约。** 可新增方法，不得删除 / 改名 / 改变现有语义（`state()` / `inv()` / `newGame()` / `kill()` / `tp()` / `openMeeting()` / `events()` / `frames()` / `replay()` / `litZone()` 等被 `test-v3.cjs` 直接依赖）。
6. **`js/engine/clock.js` 是未接线的历史模块**（头部自述「本批不接入引擎」，写死 90 s 夜）。相位真源在 `sanity.js` 的 `NIGHT.len` 与 `game.js` 的 `m.phase`；不要把它当相位真源。
7. **夹具三规矩**（`AGENTS.md` §一.5）：`newGame()` 会整个换掉 `G`，必须之后取 `g`；`openMeeting('day')` 后要走完 `startVote → closeVote → finishMeeting`；「把闲人停到某处」必须停暗舱，停亮会议室会凭空多出目击者。
8. **加载顺序**：`ai/sanity.js` 必须早于 `ai/traits.js`；`t2/*` 在 `game.js` 之前。新增文件只能插在 `index.html`，别处不许动态注入。
