## 四、后续改进建议（结合实操体验）

1. **操作键位模式切换（高优先级）**：目前移动为「点击地面」，而 `W/A/S/D` 分别绑定为交互/出刀/搜尸/收尸，建议在设置中增加「`WASD` 走位模式（`E` 交互 / `Q` 出刀 / `F` 开枪 / `R` 报告）」开关，并让出刀半圆预览随鼠标方向实时旋转。
2. **幽灵态与会议节奏优化**：已阵亡玩家在会议期缺乏加速或跳过 AI 讨论的手段，建议为阵亡玩家提供 `2x/4x` 讨论加速或跳过按钮，并强化幽灵做任务的即时进度反馈。
3. **残局博弈双向提示**：最后一名异形触发全图+资源透视时，同步向存活人类广播高危警报，引导人类从单走转为抱团控灯与持枪防守。
4. **会议结构化发言分组**：将结构化模板按钮按「指控站边 / 目击证据 / 自证不在场」三类分色分组，并在点选席位后在小地图高亮近期目击舱室。
