# 方案 · 双分模型（信任分 T + 情绪分 E）

> **状态**：提案，**未改任何游戏代码**（2026-11-19）
> **用户口径**：
> 「分值最好就是收束成一个信任分加个人看待分」「嫌疑分去掉，并入信任分」
> 「目击出刀这些异形只能做出来的，直接顶满，不会被任何伪装行为降下去」
> 「其他一律伪装行为或者可疑行为都是从信任分里面加减」
> 「情绪分属于一个小分支……影响投票、开枪，但不影响理智推断」
> **取代关系**：本文的分数模型**取代** `docs/AI-DEED-SPEECH-PLAN.md` 第 3.4 节里
> 「sus / cred / trust / grudge / reliability 五轴并存」的写法；行为总线与言语受体的设计仍然有效。
> **真源纪律**：数值仍进 `js/ai/sanity.js`；本文不复制现有数值，只写公式与映射。

## 0. 一句话

全场只留两张表：

- **信任分 T**（主线，**−1 ~ +1 双极轴**）：正轴 = 可信，负轴 = 可疑，0 = 中立。
  这是把既有 `cred` ±0.5 刻度**整体放大 2 倍**后的轴，加减分权重与阈值同步 ×2。
  目击异形专属行为 → **T=−1 并锁死**，任何伪装都抬不回来；其余可疑/可信行为都在这张表上加减。
- **情绪分 E**（支线，−1~+1）：我对他这个人的观感（怨 / 恩 / 惧 / 亲）。
  只影响「在已经可疑的人里先投谁、先打谁、救不救」，**不参与身份推断**。

嫌疑分、信誉分、准-确证、异形眼里的"像人度"全部并入 T 或改为派生量；
感恩、记仇、亲近、畏惧全部并入 E。

## 1. 研究：社交推理游戏里玩家真实会有什么情绪

联网查了 Among Us / Werewolf / Mafia 的玩家心理分析，反复出现的不是"理性推理"，而是下面六类。
它们直接决定了 E 该记什么、影响什么。

| 情绪 | 触发 | 玩家实际行为 | 来源 |
|---|---|---|---|
| **偏执 / 过度警觉** | 信息不对称、有人被刀 | 盯着每个人的走位找"破绽"；一旦怀疑就只找支持怀疑的证据（确认偏误） | tsight《Among Us 船员心理分析》 |
| **背叛感 / 负 reciprocity** | 被朋友投出去、被保过的人反咬 | 下一局记仇、反咬、不再相信；现实中也会留下芥蒂 | advance.automator.ai《Why Is Among Us So Popular》 |
| **被冤的焦虑 / 聚光灯效应** | 自己被点名、被要求自证 | 过度解释、抢话、或干脆沉默；越急越像 | gametestedpro《The Psychological Collapse of Trust》 |
| **误投后的愧疚 / 认知失调** | 投出无辜者、翻牌后发现错了 | 下一轮更保守、更容易弃票、更愿意替被冤者说话 | tsight / mechanicsofmagic |
| **从众 / 责任分散** | 两三个人咬同一个人 | "三个人都这么说，那我也投"；不是证据变强，是气势起来了 | tsight / 现有 `votePressure` |
| **不确定性下情绪替代推理** | 证据 50/50、时间紧 | 靠"感觉"投票；作者自述"沟通从推理变成情绪" | mechanicsofmagic 亲历记录 |

**对本方案的直接结论**：

1. 情绪必须**在证据模糊时权重最高**，证据清楚时让位给 T。这是"少部分根据情绪分"的精确实现。
2. 情绪的主要出口是**投票与开枪的目标选择**，不是"判断谁是异形"。
3. 被冤、被救、被背叛、被跟踪这四类事件必须留下可复述的记忆，否则情绪没有来源。
4. 愧疚/从众是**调节项**，不是第四个分数；它们只改权重，不单独记账。

## 2. 现状：九条轴，互相打架

| 轴 | 含义 | 写入点 | 读取点 | 问题 |
|---|---|---|---:|---|
| `sus` | 嫌疑 0~1 | `susAdd` 42 处 | 35 处 | 与 `cred` 各记一本账，同一个人可以"既可疑又可信" |
| `cred` | 信誉 −0.5~1.2 | `credAdd` 6 处 | 12 处 | 已经是双极轴，却和 sus 并行 |
| `known` | 亲眼确证 | 目击分支 | 45 处 | 事实上的"锁死"，但没有和 sus 合并 |
| `almost` | 准-确证 | `evalAlmost` | 21 处 | 存了一份本可从 sus + 种类推导的状态 |
| `trust` | 感恩 0~2 | `trustAdd` | 8 处 | 个人情绪，却与 cred 混称"信任" |
| `grudge` | 记仇 0~2 | `grudgeAdd` | 6 处 | 只影响投票，没进入开枪 |
| `warm` | 聊得来 0~1 | 会议 | 5 处 | 只影响走位，几乎空转 |
| `reliability` | 证言可信度 0.2~0.8 | `reliaAdd` | 5 处 | 第三套"信任"，与 cred/trust 语义重叠 |
| `humanT` | 异形眼里的"像人度" | `humanishAdd` | 15 处 | 与 `identityAxis` 是同一件事的两个写法 |

**核心问题**：`beliefOf = max(sus, axisThreat(cred))` 是两条账的临时合流；
`identityAxis = prior + cred` 又把 sus 排除在外。于是同一个人的"可疑"和"可信"可以同时很高，
AI 在不同决策里读不同的账，玩家听到的话和 AI 实际的想法对不上。

## 3. 目标模型

### 3.1 信任分 T（双极轴，−1 ~ +1）

**定义**：`T(a, i) ∈ [−1, +1]`。这是把既有身份轴 `cred` 的 **±0.5** 刻度
（`IDENTITY.evidenceW × min(0.5, cred)`，下限 −0.5，见 R12.6）**整体放大 2 倍**后的双极轴；
所有加减分权重与阈值同步 ×2，语义位移与旧版一致：

| 区间 | 含义 |
|---|---|
| `+1` | 完全可信（像人类） |
| `0` | 中立（50/50，没有任何证据） |
| `−1` | 确认异形（**锁定**） |

- **正轴**：可信行为 → T 往 `+` 走。
- **负轴**：可疑 / 伪装行为 → T 往 `−` 走。
- **锁定**：目击异形专属行为 → 直接钉到 `−1`，此后不再接受任何正向更新。
- **起始值不是 0**：`T0 = 2 × identityPrior − 1`（人类占多数时为正，约 `+0.46`）。
  0 是"50/50"，不是"开局默认"；开局默认应该反映 4/15 的基础比例。

判定层统一用 `h = (T + 1) / 2`（0~1）参与现有公式：
`T=−1 → h=0`（确认异形），`T=0 → h=0.5`，`T=+1 → h=1`（完全信任）。

#### 刻度同步（±0.5 → ±1，全部 ×2）

| 项 | 旧 ±0.5 刻度 | 新 ±1 刻度 |
|---|---|---|
| T 范围 | −0.5 ~ +0.5 | **−1 ~ +1** |
| 单次证据位移 | w | **2w** |
| 锁定 | −0.5 | **−1** |
| 非锁定下限 | −0.40 | **−0.80** |
| 远处目击单次上限 | 0.45 | **0.90** |
| `almost.foe` | h≤0.25（T≤−0.25） | h≤0.25（**T≤−0.5**） |
| `almost.friend` | h≥0.75（T≥+0.25） | h≥0.75（**T≥+0.5**） |
| 开局先验 | prior−0.5（≈+0.23） | **2prior−1（≈+0.46）** |
| 情绪权重 | `1−2|T|` | **`1−|T|`** |

> **这不是换尺，是同步放大**：所有 `EV_W` / `CRED.gains` 的 w 乘 2、所有阈值乘 2，
> 所以同一事件在 T 轴上的相对位移与 ±0.5 版完全一致。

#### 正轴 / 负轴各记什么

| 轴 | 行为 | 方向 |
|---|---|---|
| **正轴** | 做任务完成、修好故障、合闸、医疗包施救、拖人进医疗间、被当众辩护、被救 | `+` |
| **负轴** | 假做任务、假装修、弃修、拖尸、拖离医疗间、开枪（非处决）、被拘留、远距目击出刀、被传闻指控 | `−` |
| **锁定** | 近距离（≤4.5 格）目击出刀 / 钻管道 / 破坏 / 停摆机器人 / 拉闸断电 / 出刀红身 | 直接 `−1` |

#### 更新公式（在 h 轴上算，T = 2h − 1，权重 ×2）

```
可疑：h ← h − w × (0.45 + 0.55·h)      ⇒  T = 2h − 1
可信：h ← h + w × (0.45 + 0.55·(1−h))  ⇒  T = 2h − 1
```

- `w` 仍读 `EV_W` / `CRED.gains`，**权重表不新造**；T 轴上的位移是 `2w`，这是刻度同步。
- 在 T 轴上等价于：可疑 `ΔT = −2w(0.45+0.55h)`，可信 `ΔT = +2w(0.45+0.55(1−h))`。
- 越接近 `−1` 越难再降，越接近 `+1` 越难再升 —— 与现在 `susAdd` 的边际递减同源。
- ⚠ **先验并入 T 后，同样 w 的实际位移会比旧版大**（旧版 `sus` 从 0 起算，新版 h 从 `prior` 起算）。
  这些权重必须在 P4 用 1000 局重标，不能直接沿用旧读数。

#### 锁定（取代 `known`）

```
目击异形专属行为（出刀 / 钻管道 / 破坏 / 停摆机器人 / 拉闸断电 / 出刀红身）
且距离 ≤ CONFIRM.nearR（4.5 格）
→ T = −1，lock = { kind, night, t, room }
→ 此后任何正向更新一律跳过（伪装、救人、做任务都抬不回来）
→ 不衰减、不遗忘、不覆盖
```

- `lock` 是布尔事实，不是分数；`known` 的全部读取点改为 `isLocked(a,i)`。
- **误认**（MISID 20%）照旧：锁错人也是锁，这是社交代价，不修正。
- 远处看见（>4.5 格）**不锁**，只按权重扣 T，且单次扣分上限 `LOCK.farCap`
  （建议 0.90，h 轴 0.45），保证"只有亲眼近距离看见才能把人钉死"。

#### 非锁定的下限

```
T 的下限 = LOCK.floor（建议 −0.80，即 h=0.10）
```

没有锁的人，无论多少可疑行为叠加，都不能被扣到 `−1`。
这条对应现在的"cred 负端下限 −0.5，再深只能由 known 给"——
现在只有 `lock` 能到达 `−1`。

#### 衰减

```
每夜：T ← T0 + (T − T0) × rate
  T < T0（负轴侧）: rate = 0.78，本夜无新证据再 ×0.55
  T > T0（正轴侧）: rate = 0.92
lock: 不衰减
```

- 负轴掉得快、正轴留得久，对应现在 `CARRY.decaySight 0.72` 与 `CRED.decay 0.92` 的差异。
- `T0` = 当前 `2 × identityPrior − 1`（按存活人数与已出局阵营推算），不是固定 0。
- 夜间读取（开枪/报警）时，负轴侧再 ×0.70（沿用 `CARRY.nightReadSec`）。

#### 派生量（不再存储）

| 旧状态 | 新写法（用 h 表述，便于对照旧阈值） |
|---|---|
| `almost.foe` | `!lock && h ≤ 0.25`（T ≤ −0.5）`&& 实证≥1 && 证据种类≥2 && 新鲜` |
| `almost.friend` | `h ≥ 0.75`（T ≥ +0.5）`&& 正经行为种类≥2 && 新鲜` |
| `identityAxis` / `hostileProb` | 人类敌对 `= 1−h`；异形敌对 `= h` |
| `humanT` | 删除；异形读同一个 T，高 T = 更像对手 |
| `suspect` | 指针：当前 `h` 最小的人；不是分数 |

> `almost` 的两个阈值是按**置信度**重定的：`h≤0.25` ≈ 75% 异形、`h≥0.75` ≈ 75% 人类；
> 不再照搬旧版 `sus≥0.5` 与 `cred≥0.5` 两个不同量纲的阈值。

### 3.2 情绪分 E

**定义**：`E(a, i) ∈ [−1, +1]`。负端 = 怨/惧，正端 = 恩/亲。

#### 四类来源（复用现有 GRATITUDE / grudge 的量级）

| 来源 | 事件 | 方向 | 建议量级 |
|---|---|---|---:|
| 怨 | 被他当众指控 / 被他投 / 被他诬陷 | − | 0.45 / 0.30 / 0.35 |
| 惧 | 被他刀（幸存）/ 被他开枪（幸存）/ 被他跟踪 | − | 0.90 / 0.60 / 0.25 |
| 恩 | 被他救起 / 被他拖进医疗间 / 被他当众辩护 | + | 0.55 / 0.35 / 0.45 |
| 亲 | 长期同行 / 一起指控同一人 / 他听我的指令 | + | 0.10 / 0.10 / 0.06 |

```
E ← clamp(−1, 1, E + w × (1 − 0.5·|E|))
每夜 ×0.80，|E| < 0.05 遗忘
```

#### 调节项（不单独记账）

| 调节 | 触发 | 作用 |
|---|---|---|
| 愧 | 上一轮投出的是人类 | 下一场 `λ` ×0.6，更易弃票 / 替被冤者说话 |
| 冤 | 自己被冤枉且被澄清 | 对指控者的 `E` 额外 −0.2，会上更想点破他 |
| 慌 | 存活人数接近、连续死人 | `λ` ×1.3，投票更冲动（上限 1.5） |
| 确认偏误 | `T < 0.4` | 后续负面证据 ×1.15、正面证据 ×0.85（只改权重，不改分数） |

### 3.3 两个分数怎么分工

| 行为 | 读什么 | 说明 |
|---|---|---|
| 判断"他是不是异形" | **只读 T**（换算 h） | 情绪一律不进 |
| 会议指控的门槛 | **只读 T** | 没有 T 依据，情绪不能凭空造出指控 |
| 证言采信权重 | **只读 T** + 发言准确率日志 | 准确率是计数，不是分数 |
| 投票选谁 | `1−h` 为主 + `λ·(−E)` | 情绪只在候选人之间改优先级 |
| 开枪选谁 | `1−h` 为主 + `λ·(−E)` | 同上，且必须先过开枪门槛 |
| 救谁 / 拖谁 | `h` 为主 + `λ·max(0,E)` | 恩情提高救援优先 |
| 跟谁走 / 躲谁 | `E` 的符号 | 纯走位，不影响判断 |
| 台词语气与理由 | `E` | 怨/恩/惧决定他说什么，不决定他信什么 |

### 3.4 决策公式

```
h(i)           = (T(i) + 1) / 2          // 0 确认异形 · 0.5 中立 · 1 完全信任
uncertainty(i) = 1 − |T(i)|              // T=0 时最不确定；T=±1 时为 0
λ_eff(i)       = λ × uncertainty(i)       // 情绪只在模糊时有权重

投票候选 = { i | 1−h(i) ≥ θ_vote 且 !isPatronUnlessLocked(i) }
投票得分 = (1−h(i)) + λ_eff(i) × (−E(i))

开枪候选 = { i | 1−h(i) ≥ θ_shoot }
开枪优先 = (1−h(i)) + λ_eff(i) × (−E(i)) − 距离惩罚

救援优先 = h(i) × 0.2 + max(0, E(i)) + 距离惩罚
```

- `λ` 建议 **0.15**（投票）、**0.10**（开枪）。
- **硬护栏**：`E` 不能把 `h > 0.5`（T > 0）的人推进候选集；锁定的目标 `uncertainty=0`，
  情绪完全失效 —— 亲眼看见出刀的人，不会因为"他救过我"就不投他。
- 这条护栏就是用户说的"不影响理智推断的行为"。

### 3.5 决策栈（前后对比）

```
现在：
  sus ─┐
  cred ─┼→ beliefOf = max(sus, axisThreat(cred)) → 投票/开枪
  known ─┘        ↑
  trust/grudge ──┘（只影响投票的两条支路）

之后：
  T（含 lock）──→ 身份判断 h=(T+1)/2 / 指控门槛 / 证言权重 / 候选集
       └─→ 投票得分 = 1−h + λ·(−E)
  E ────────────→ 同样进入得分，但只在候选集内、且只在 T 模糊时有权重
```

```
mind.belief[i]  = T   // 信任分（主线）
mind.emo[i]     = E   // 情绪分（支线）

```

旧字段 `mind.trust`（感恩）迁到 `mind.emo` 后删除，避免两个"trust"。

## 5. 情绪分类表（4 核心 + 4 调节）

| 情绪 | 类型 | 触发事件 | 行为出口 | 是否单独记账 |
|---|---|---|---|---|
| 怨 | 核心 | 被指控 / 被投 / 被诬陷 | 投票反咬、会上点名、证言打折 | 是（E 负向） |
| 惧 | 核心 | 被刀 / 被枪 / 被跟踪 | 躲开他、拒绝同行、优先投他 | 是（E 负向） |
| 恩 | 核心 | 被救 / 被拖 / 被辩护 | 不投他、替他说话、优先救他 | 是（E 正向） |
| 亲 | 核心 | 长期同行 / 共同指控 / 听指令 | 跟着走、附议、投票跟随 | 是（E 正向，弱） |
| 愧 | 调节 | 投出人类 | `λ` 降低、更易弃票 | 否（临时系数） |
| 冤 | 调节 | 被冤枉后澄清 | 对指控者 E 额外 −0.2 | 否（一次性写入 E） |
| 慌 | 调节 | 残局 / 连续死人 | `λ` 提高、更冲动 | 否（临时系数） |
| 傲 / 确认偏误 | 调节 | T 已低 | 负面证据加权、正面打折 | 否（权重） |

**为什么只有 4 个核心**：用户要的是"小分支"。
8 个核心会变成第二套人格系统；4 个核心 + 4 个系数足够覆盖研究里反复出现的模式。

## 6. 迁移方案（不一次性推翻）

这是核心认知层的重构，直接改会同时动 42 个 `susAdd`、45 个 `known` 读取、21 个 almost 判定。
分五步，每步都能单独回滚。

> **P0 基线（2026-11-19，20 局 / 73 对）**：旧 `sus` 的 #1 怀疑对象与影子 `T` 的 #1 不同的比例是
> **41.1%（30/73）**。这是最粗的影子（未含证据种类 / 衰减 / 锁），只说明两套账分歧很大，
> **不能直接切**；P1 双写后再用会议快照统计真正的投票 / 开枪分歧率。
> 工具：`node tools/trust-shadow.cjs 20`；探针：`_t.trustShadow(观察者席, 目标席)`。

### 6.1 兼容层（P0~P2 必须）

- `susOf(a,i)` 返回 `1−T`（旧读取点不改也能跑）。
- `credOf(a,i)` 返回 `T − 0.5`（保持旧符号习惯）。
- `mind.sus` / `mind.cred` 作为**镜像对象**继续被写，供旧循环 `for (const k in mind.sus)` 使用。
- `mind.known` 作为 `lock` 的镜像继续存在，P3 才删。
- `_t.state()` 新增 `belief` / `emo` / `lock`，旧字段保留到 P3。

### 6.2 双写的一致性规则

**只允许一处写 T**：`beliefAdd(a, i, w, reason, ev)`。
`susAdd` / `credAdd` / `knownOverride` 全部改为它的薄包装，禁止在业务代码里直接改 `mind.belief`。
同理，E 只允许 `emoAdd(a, i, w, reason)` 一处写。

## 7. 门禁与探针

| 断言 | 现在 | 之后 |
|---|---|---|
| 目击出刀 → `known` | `mind.known[i]` 存在 | `lock[i]` 存在且 `belief[i] === −1` |
| 伪装抬不动锁死目标 | 无 | 连续 10 次 `taskDone` 后 `belief[i]` 仍为 −1 |
| 非锁定下限 | cred floor −0.5 | `belief[i] >= −0.80`（无 lock 时，即 h≥0.10） |
| 远处目击不锁 | `far` 分支 | `lock` 不存在，`belief` 降幅 ≤0.90（h 轴 0.45） |
| 情绪不改身份 | 无 | 把 E 设为 ±1，`belief` 与投票候选集不变 |
| 情绪只在候选集内 | 无 | E=+1 的锁定目标仍被投；E=−1 的高 h 目标不被投 |
| 证言权重 | `reliability` | `0.4 + 1.2·h`，锁死发言者权重 0 |
| 旧读数兼容 | `state().sus` | P3 前保留镜像，P3 后改 `state().belief` |

`_t.state()` 建议新增：

```js
belief: { [i]: T },
emo:    { [i]: E },
lock:   { [i]: kind },
```

## 8. 平衡校准

合并两本账是**明确的平衡位移**，必须用 1000 局量，不许凭感觉定档。

### 8.1 先验风险

| 变化 | 方向 | 可能后果 |
|---|---|---|
| sus 与 cred 合并 | 异形演好人可以直接抵消可疑行为 | 异形变强，人类胜率下降 |
| 锁死不可洗白 | 人类目击一次就锁死 | 人类变强 |
| 情绪进入开枪 | 记仇的人更容易开枪 | 误杀增加，人类可能变弱 |
| 情绪只在 T 模糊时生效 | 证据清楚时不受影响 | 波动被限制 |

### 8.2 校准顺序

1. 先固定 `lock` 与 `T` 的权重缩放（0.8 / 1.0 / 1.2 三档），跑 3 种子 × 300 局粗筛。
2. 选最接近 52.3% 的一档，再跑 1000 局确认。
3. 最后才调 `λ`（0.10 / 0.15 / 0.20），看"情绪影响票占比"是否落在 5~15%。

### 8.3 验收指标

| 指标 | 目标 |
|---|---|
| 人类胜率 | 50~55%（现 52.3%） |
| `almost.foe` / 局 | 与现版差 ≤20% |
| 锁死目标被投率 | ≥95%（人类侧） |
| 锁死目标被伪装抬回 | **0 次** |
| 情绪影响票占比 | 5~15% |
| 误投人类率 | 不高于现版 +2pp |
| 1000 局时长 | ≤ +10% |

## 9. 风险

| 风险 | 后果 | 对策 |
|---|---|---|
| 合并后异形过强 | 演好人洗掉可疑 | 锁定不可洗；非锁定下限 −0.80；单次负向上限 0.90 |

## 10. 待你拍板

1. **T 的轴向**：本文定义 `T ∈ [−1, +1]` 双极轴 —— `+1` 完全信任、`0` 中立、`−1` 确认异形并锁定。
   正轴记可信行为，负轴记可疑/伪装行为，锁定直接钉到 `−1`；所有权重与阈值按 ±0.5 旧刻度 ×2 同步。
2. **非锁定下限 −0.80（h=0.10）**：没有亲眼目击的人，最多被扣到"几乎确定"而不是 −1。
   这条是为了守住"只有目击才能钉死"，要不要保留？
3. **远处目击的单次上限 0.90（h 轴 0.45）**：4.5 格外看见出刀只重扣、不锁。
   这会让"远远看见"变成可洗白的强怀疑；要不要更严（h 0.30）或更松（h 0.60）？
4. **λ 的档位**：投票 0.15 / 开枪 0.10 是本文建议；这决定"情绪能翻多少盘"。
5. **情绪是否进开枪**：你明确说"影响投票、开枪"，本文按此设计；
   但如果你希望开枪更理性，可以只保留投票与救援。
6. **`almost` 是否保留为台词档位**：存储删掉后，台词仍可分「我确定 / 我基本确定 / 我怀疑」三档，
   由 T 的区间（h≤0.25 / h≤0.5 / 其余）决定。要不要保留这三档措辞？
7. **P0 是否先做影子对比**：我建议先跑 300 局双写对比，看新旧模型在投票目标上的分歧率，
   再决定是否切换。这样不会一上来就把平衡打崩。
