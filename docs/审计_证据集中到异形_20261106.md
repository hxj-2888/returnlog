# 审计：证据到底怎么集中到真异形身上

> 只读审计 + 非行为遥测。基线：2026-11-06 改动前 1000 局（seed 20261030，人类 57.5%），
> 最终批次见 `tools/mc-report.md`（人类 59.5%，含 RUSH 1.5 / 保安 6 格 / 当众合闸 / 8 管道）。
> 本文只回答“证据链怎么工作”，不修改任何判定。

## 一、结论先行

把证据分成两层看，结论非常干净：

| 通道 | 目标=异形 | 目标=人类 | 判断 |
|---|---:|---:|---|
| 硬确证写入 `knownWrites` | **4.115** | **0** | 100% 命中异形 |
| 确证票 `knownVotes` | **2.047** | **0** | 100% 投给异形 |
| 确证驱逐 `ejectByKnown` | **1.581** | **0** | 100% 逐出异形 |
| 准-确证 `almost.foe` | 1.902 | **5.013** | 约 **72% 指向人类** |
| 准-确证驱逐 `almostEject` | 0.461 | **0.839** | 软通道净伤害大于收益 |

（数值为改动前 1000 局每局均值；最终批次同口径见 `tools/mc-report.md` 的「证据命中目标」表。）

**一句话：真正把人推到异形身上的是 `known`（亲眼确证），不是 `sus`/`almost`。**
硬确证只接受“人类做不到的行为 + 近距离目击”，因此几乎不会误伤；软通道靠多类弱证据凑准-确证，
反而大多数落在人类身上。

## 二、硬证据链：只有一条入口

`noticeAction(actor,x,y,rad,kind,victim)`（`js/game.js`）是唯一的人类目击证据入口：

1. 目击者必须是**活着、非异形、非倒地、非拘留、注意力 online** 的人类；
   AI 异形不作为目击者写入，避免借证人表反推队友。
2. 先按 `aiCanSee` + `rad` 过滤；`dw > CONFIRM.nearR (4.5)` 时只走 `susAdd`，
   并在证据上打 `far=1`，**不写 known**。
3. 只有 `alienAct`（出刀 / 钻管道 / 破坏 / 停摆机器人）或 `breakerOff`（拉闸断电）
   且 `near` 时，才写：
   ```js
   w.mind.known[actor.i] = { kind:'saw_'+kind, conf:0.95, ... };
   w.mind.sus[actor.i] = 1;
   knownOverride(w, actor.i);   // 删 almost.friend、清 cred，不动 trust
   ```
4. 第二条入口是 `trackNight()` 的刀者红身：附近人类看到 `redT>0`，同样写 `known('saw_red')`。
   红身只由真实出刀挂上，人类没有刀，所以同样是异形专属。

`known` 的读取端很硬：

- `startVote` 里 `known` 票优先，不被讨论改票、不被弃票盾挡；
- `bestKnownTarget()` 驱动指控、投票、开枪与追击距离；
- `known` 跨夜保留（`mindReset` 只清 `mem`，不清 `known`），一次确证可以锁定后续每场会议。

### 2.1 来源拆解（改动前 1000 局，每局均值）

| `knownBy` 来源 | 次数/局 | 说明 |
|---|---:|---|
| `saw_red` | 2.593 | 刀者红身，最大来源（约 63%） |
| `saw_knife` | 0.871 | 近距离看见出刀 |
| `saw_pipe` | 0.382 | 近距离看见钻管道 |
| `saw_sabotage` | 0.269 | 近距离看见破坏设备 |
| `saw_bot` / `saw_breaker` | 0（AI 对 AI） | AI 异形很少在有目击者时停摆机器人 / 拉闸 |

红身是“贴脸出刀”的副产品；它把“出刀”从一次性事件变成**可被后续目击者反复读取**的证据，
所以贡献最大。`saw_breaker` 在 AI 对 AI 里为 0，是因为 `BREAKER.witnessCap=1`：
有目击者时 AI 异形根本不拉闸。**“守闸确证”主要是玩家侧才吃得到的知识。**

### 2.2 为什么 `knownWritesHuman = 0`

`alienAct` 本身带 `!!actor.alien`，所以只有异形触发出刀/管道/破坏/停摆；
红身的 `redT` 只由真实出刀挂上，而人类没有刀。唯一的理论误确证入口是
`breakerOff`：人类也可以拉闸断电，附近人类看见会写 `known`。
AI 对 AI 里没有人类 AI 拉闸（人类 AI 只合闸复电），所以实测为 0；
**真人局里如果玩家故意拉闸断电，这条会变成真实的误确证入口**，这是设计取舍，不是 bug。

## 三、软通道：`almost` 大多数打在人类身上

`susAdd()` 接受所有目击/听觉/矛盾/空口指控等弱证据；`almost.foe` 在
`sus >= foeSus` 且“不同种类的非传闻证据 ≥ 2 类”时成立。它**不是**确证，但会在
`startVote` 里获得票权（先于 sus 分支）。

实测它的问题是目标错位：

- `almostAlien` 1.902 vs `almostHuman` 5.013；
- `almostEjectAlien` 0.461 vs `almostEjectHuman` 0.839。

噪声主要来自这些“人类也会做”的行为被当成多类证据：

- 开枪 / 拖尸 / 反常拖尸 / 被拘留 / 在场矛盾；
- `contradiction_*`（时间线拆谎）本身会落在说真话的人身上；
- `defended_suspect`、`avoid`、`silent` 等行为线索；
- 异形构陷的 `heard_frame` / `heard_claim`（听众无法区分真假）。

`knownOverride` 会清掉 `almost.friend` 和 `cred`，所以一旦硬确证落地，软印象会被压掉；
问题在于**硬确证还没发生时**，软通道会先推动一次错误驱逐。

## 四、证据是怎么“集中”的

不是靠一个“总嫌疑分”，而是三条物理约束叠加：

1. **行为专属**：`known` 只接受人类做不到的动作（刀 / 管道 / 破坏 / 停摆 / 红身 / 拉闸）。
2. **距离门槛**：只有 `CONFIRM.nearR = 4.5` 格内的目击才升级为 `known`；
   远处的目击只加 `sus`，不会直接定罪（`farSight` 每局 1.736 次）。
3. **硬覆盖**：`known` 写入后 `sus=1`、删 `almost.friend`、清 `cred`，
   `credAdd` 对已 `known` 对象直接 return；讨论/证言改不了 `known` 票。

因此，“证据集中到真异形”是**结构性的**：
只有异形能产生可确证行为，且必须被人类在 4.5 格内看见；
其余所有推断都只能进软通道，软通道的准确率目前明显低于硬通道。

## 五、风险与后续（未改行为）

- **最大噪声不是 random，而是软通道的目标错位**：如果要提高驱逐准确率，
  优先收紧 `almost.foe`（例如要求目标专属证据、或把 `almost.foe` 从“票权”降回“权重”），
  不要去动 `CONFIRM.nearR` 或 `known` 的写入规则。
- **`knownWritesHuman` 在真人局可能非 0**：玩家拉闸断电被近距离看见会被确证。
  如果不想让“玩家拉闸”被当成异形，需要在 `noticeAction` 区分玩家/异形的拉闸语义；
  但这会动摇“拉闸 = 身份级证据”的设计，需单独裁定。
- **红身是最大确证来源**（2.593/局），也是最容易被“贴脸出刀”制造的证据；
  如果觉得异形被锁得太快，应先调红身时长/出刀距离，而不是放宽 `known`。
- **管道网络从 6 扩到 8 个舱室**会同时增加 `saw_pipe` 的确证机会和异形的机动性，
  这是一次平衡位移，不是纯证据改动；跨批比较时必须看同一份配置快照。

## 六、2026-11-06 规则变更后的复测（实际视野 + 队友洗白）

- 1000 局（seed 20261030）：**人类 85% / 异形 15% / 超时 0**；
  夜 3.991、驱逐 3.987（人类 **1.114** / 异形 2.873）、误逐 **27.94%**。
- `knownWritesAlien` 3.875 / `knownWritesHuman` **0**；`almostAlien` 3.801 / `almostHuman` 5.879，
  但 `almostEjectAlien` 1.214 / `almostEjectHuman` **0.672**；
  `busAccusals` 0.131 次/局（12% 的局）。
- **归因更正**：此前把 85% 归因于 `almostTargetAllowed` 是错的 ——
  当前代码里没有这个函数；85% 在无该函数的代码上可复现。
  真正的变量是“亮房整间可见 + 远处目击仍按全额喂 `almost`/`sus`”：
  `farSight` 从 1.7 涨到 8.2 次/局，`almostAlien` 从 2.0 涨到 3.8，`almostEjectAlien` 从 0.45 涨到 1.21。
  **不是 almost 的阵营分流，也不是队友洗白。**

## 七、2026-11-06 视野统一后的复测（AI 与玩家完全一致）

- 1000 局（seed 20261030）：**人类 87.0% / 异形 13.0% / 超时 0**（95% Wilson 84.77~88.94）；
  夜 3.928、驱逐 4.021（人类 **1.078** / 异形 2.943）、误逐 **26.8%**。
- `farSight` 9.295、`knownWritesAlien` 2.879 / `knownWritesHuman` 0、
  `almostAlien` 4.830 / `almostHuman` 5.658、`almostEjectAlien` 1.663 / `almostEjectHuman` 0.659。
- **视野一致没有降低人类胜率，反而 +2pp**。把 AI 目击人为退回 6 格是 57.6%，但那是“比玩家看得少”，
  不能作为修法；在一致视野下把远处证据降级（不进 `almost`、不设 `suspect`、`farSusMul 0.35`）
  是 **71.6%**（500 局），仍高于目标区间。
- **结论**：剩余差距主要是 **4 次正确驱逐 vs 11 次击杀** 的胜负结构，不是视野。
  下一步应动胜负结构或异形社交/目标（`identityAlien` 尚未接到异形侧），
  不要再改视野或 `known`。
